Урок 9. Списки в HTML

1. Зачем нужны списки

В HTML есть три типа списков, каждый — для своей задачи:

Тег Название Внешний вид Когда использовать
<ul> Маркированный (unordered list) • • • Порядок не важен: ингредиенты, свойства
<ol> Нумерованный (ordered list) 1. 2. 3. Порядок важен: шаги, инструкция
<dl> Список определений (description list) термин → значение Словарь, FAQ, метаданные
Правило выбора: если порядок пунктов можно поменять без потери смысла — <ul>. Если нельзя (шаги 1, 2, 3) — <ol>.

2. Маркированный список <ul>

<ul> (unordered list) — список с маркерами (точками, кружками). Каждый пункт — внутри <li> (list item). 

<ul>
    <li>Мука</li>
    <li>Сахар</li>
    <li>Яйца</li>
</ul>
Результат:
  • Мука
  • Сахар
  • Яйца

Когда использовать <ul>:

  • Перечисление однотипных предметов
  • Список ингредиентов
  • Характеристики товара
  • Пункты меню навигации (в связке с CSS)
  • Любой список, где порядок не важен

3. Нумерованный список <ol>

<ol> (ordered list) — список с автоматической нумерацией. Внутри — те же <li>. 

<ol>
    <li>Разогрейте духовку до 180°C</li>
    <li>Смешайте муку и сахар</li>
    <li>Добавьте яйца</li>
    <li>Выпекайте 20 минут</li>
</ol>
Результат:
  1. Разогрейте духовку до 180°C
  2. Смешайте муку и сахар
  3. Добавьте яйца
  4. Выпекайте 20 минут

Атрибуты <ol>

Атрибут Значения Что делает
type 1 (по умолчанию), A, a, I, i Тип нумерации: цифры, большие/маленькие латинские, римские
start Число С какого номера начать (например, start="5")
reversed булев Обратный порядок (от большего к меньшему)

Пример: латинская нумерация

<ol type="A">
    <li>Первый</li>
    <li>Второй</li>
    <li>Третий</li>
</ol>
Результат:
  1. Первый
  2. Второй
  3. Третий

Пример: старт с 5

<ol start="5">
    <li>Пятый пункт</li>
    <li>Шестой пункт</li>
</ol>
Результат:
  1. Пятый пункт
  2. Шестой пункт

Пример: обратный порядок

<ol reversed>
    <li>Третий</li>
    <li>Второй</li>
    <li>Первый</li>
</ol>
Результат:
  1. Третий
  2. Второй
  3. Первый

Атрибут value у <li>

У пункта <li> есть атрибут value — задаёт конкретный номер:

<ol>
    <li>Первый</li>
    <li value="10">Десятый</li>
    <li>Одиннадцатый</li>
</ol>
Результат:
  1. Первый
  2. Десятый
  3. Одиннадцатый

4. Вложенные списки

Списки можно вкладывать друг в друга. Вложенный список должен находиться внутри <li> родителя, а не между <li>. 

<ul>
    <li>Фрукты
        <ul>
            <li>Яблоки</li>
            <li>Бананы</li>
        </ul>
    </li>
    <li>Овощи
        <ul>
            <li>Морковь</li>
            <li>Картофель</li>
        </ul>
    </li>
</ul>
Результат:
  • Фрукты
    • Яблоки
    • Бананы
  • Овощи
    • Морковь
    • Картофель
Частая ошибка: вкладывать <ul> между <li>, а не внутри. Так браузер сам перестроит структуру, но код станет невалидным.

Смешанные вложенные списки

<ol>
    <li>Подготовка
        <ul>
            <li>Достать ингредиенты</li>
            <li>Разогреть духовку</li>
        </ul>
    </li>
    <li>Замес</li>
    <li>Выпечка</li>
</ol>
Результат:
  1. Подготовка
    • Достать ингредиенты
    • Разогреть духовку
  2. Замес
  3. Выпечка

5. Список определений <dl>

<dl> (description list) — список из пар «термин — значение». Состоит из трёх тегов:

  • <dl> — контейнер списка.
  • <dt> (description term) — термин.
  • <dd> (description details) — описание.
<dl>
    <dt>HTML</dt>
    <dd>Язык разметки гипертекста.</dd>

    <dt>CSS</dt>
    <dd>Язык стилей.</dd>

    <dt>JS</dt>
    <dd>Язык программирования для веба.</dd>
</dl>
Результат:
HTML
Язык разметки гипертекста.
CSS
Язык стилей.
JS
Язык программирования для веба.

Когда использовать <dl>:

  • Словарь / глоссарий
  • FAQ (вопрос → ответ)
  • Метаданные (автор → Иван)
  • Параметры товара (цвет → красный)

Особенность <dl>

У одного <dt> может быть несколько <dd>:

<dl>
    <dt>Кофе</dt>
    <dd>Горячий напиток.</dd>
    <dd>Бодрит по утрам.</dd>
    <dd>Бывает чёрный, с молоком или капучино.</dd>
</dl>
Результат:
Кофе
Горячий напиток.
Бодрит по утрам.
Бывает чёрный, с молоком или капучино.

6. Сравнение трёх списков

<ul> <ol> <dl>
Маркер точка / кружок цифра / буква нет
Пункт <li> <li> <dt> + <dd>
Порядок важен нет да нет
Использование перечисления инструкции словарь, FAQ

7. Внешний вид по умолчанию

  • <ul> — маркеры-точки (disc), вложенные — кружки (circle), затем квадраты (square).
  • <ol> — цифры, выравниваются вправо.
  • <dl> — <dt> жирным, <dd> с отступом слева.
  • У всех — отступ слева ~40px для маркеров.

Всё это настраивается через CSS: list-style, list-style-type, padding, margin.

<ul style="list-style: none; padding: 0;">
    <li>Без маркеров</li>
    <li>И без отступа</li>
</ul>
Результат (часто используется в меню навигации):
  • Без маркеров
  • И без отступа

8. Частые ошибки

Ошибка Почему плохо
Класть в <ul> что-то, кроме <li> Невалидно (кроме вложенных <ul>/<ol>, и то — внутри <li>)
Вкладывать <ul> между <li> Ломает структуру; вкладывай внутрь <li>
Использовать <ol>, когда порядок не важен Вводит в заблуждение: цифры подразумевают последовательность
Имитировать список через <br> и • Потеря семантики для поисковиков и screen reader'ов
Использовать <dl> для верстки без семантики пар Должны быть реальные пары «термин — значение»
Забывать закрывать <li> Хотя браузер закроет автоматически, лучше писать явно

9. Вложенность и отступы в коде

Хорошая практика — отступать вложенные списки, чтобы видеть структуру:

<ul>
    <li>Первый пункт</li>
    <li>Второй пункт
        <ul>
            <li>Подпункт 2.1</li>
            <li>Подпункт 2.2</li>
        </ul>
    </li>
    <li>Третий пункт</li>
</ul>

11. Что запомнить из урока

  • Три списка: <ul> (маркированный), <ol> (нумерованный), <dl> (определения).
  • Выбор: порядок не важен → ul; важен → ol; пары «термин-значение» → dl.
  • Пункты: <li> для ul/ol, <dt>+<dd> для dl.
  • Внутри <ul>/<ol> могут быть только <li>.
  • Вложенные списки — внутри <li>, а не между ними.
  • Атрибуты <ol>: type (1/A/a/I/i), start (номер старта), reversed.
  • <li> может иметь value — задать конкретный номер.
  • Внешний вид настраивается через CSS: list-style, padding, margin.
  • Списки — семантические, а не «просто оформление». Их читают поисковики и screen reader'ы.
