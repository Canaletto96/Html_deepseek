Урок 8. HTML-сущности

1. Что такое HTML-сущности

HTML-сущность (entity, «мнемоника») — это специальный код, который начинается с амперсанда & и заканчивается точкой с запятой ;. Браузер, встретив такой код, подставляет нужный символ. 

&имя;     ← именованная сущность (например &copy;)
&#номер;   ← числовая сущность (например &#169;)
&#xHEX;    ← hex-сущность (например &#xA9;)

Все три варианта выше дают один и тот же символ: ©.

Зачем это нужно:
  • Вставить символы, которых нет на клавиатуре (©, ®, €, →, ★).
  • Показать символы, которые конфликтуют с HTML (<, >, &).
  • Добавить неразрывный пробел, тире, кавычки-ёлочки.

2. Три обязательные сущности

Эти три ты будешь использовать постоянно. Их надо знать наизусть.

Символ Сущность Что это
< &lt; Меньше (less than)
> &gt; Больше (greater than)
& &amp; Амперсанд

Почему их обязательно экранировать

Если написать < «как есть», браузер подумает, что начинается тег:

<!-- ПЛОХО: браузер решит, что <p> — это тег -->
<p>Тег <p> создаёт параграф.</p>

<!-- ХОРОШО: экранируем угловые скобки -->
<p>Тег &lt;p&gt; создаёт параграф.</p>
Результат:

Тег <p> создаёт параграф.

Важно про амперсанд: его нужно экранировать всегда, если он не является началом сущности. Например, в URL: <a href="page.php?id=5&amp;name=ivan">.

3. Неразрывный пробел &nbsp;

Обычный пробел браузер может «схлопнуть» или использовать как точку переноса строки. &nbsp; (non-breaking space) — это пробел, который не переносится и не схлопывается. 

<p>10&nbsp;000&nbsp;рублей</p>
<p>Иван&nbsp;Иванов</p>
Результат (число и имя не разорвутся при переносе):

10 000 рублей

Иван Иванов

Где используют &nbsp;:

  • Числа с разделителем: 1 000 000
  • Имена и фамилии: Лев Толстой
  • Единицы измерения: 5 кг, 10 км
  • Пустая ячейка в таблице (иначе схлопнется)

11. Числовые сущности — универсальный способ

Для любого символа Unicode можно использовать числовой код. Это удобно, если у символа нет «имени» или ты не помнишь название. 

&#60;     → <        (десятичный код)
&#x3C;    → <        (hex-код, тот же символ)

&#169;    → ©
&#8364;   → €
&#8594;   → →
&#9733;   → ★
Как найти код символа: открой https://unicode-table.com, найди символ → увидишь его десятичный и hex-код.

12. Где сущности НЕ работают

Внутри тега <script> и <style> сущности не обрабатываются! Там всё пишется как есть.

<script>
    // Это НЕ сработает:
    var s = "&copy;";

    // Это правильно:
    var s = "\u00A9";  // JavaScript-эскейп
</script>

13. Частые ошибки

Ошибка Что будет
Забыть точку с запятой: &copy Браузер может не распознать сущность
Написать &amp;copy; Покажется текст «&copy;», а не символ ©
Использовать &nbsp; для больших отступов Плохая практика — используй CSS margin/padding
Не экранировать & в URL Может сломать ссылку
Использовать &lt; вне контекста В тексте — ок. Но не пытайся так «создать тег».

Задание 1. «Текст с символами»

Создай файл 08-practice.html. Напиши абзац, в котором будут:

  • Кавычки-ёлочки: «Привет!»
  • Длинное тире: —
  • Копирайт: ©
  • Евро и рубль: € 100, 5000 ₽
  • Стрелка: →
  • Многоточие: …

Задание 2. «Показать HTML-код»

  • Напиши абзац: «Тег <p> создаёт параграф» — с экранированием.
  • Открой в браузере — увидишь текст с угловыми скобками, а не тег.

Задание 3. «Неразрывный пробел»

  • Напиши: «10 000 000 рублей» через &nbsp;.
  • Сузь окно браузера — число не должно разрываться на части.
  • Сравни с обычными пробелами — увидишь разницу.

Задание 4. «Найди код символа»

  • Открой https://unicode-table.com.
  • Найди символы: ⚡ ☕ ✈ ⚙ ❤
  • Узнай их hex-коды и вставь в свою страницу через &#x....

  • Напиши &copy без точки с запятой — что покажет браузер?
