Урок 10. Ссылки <a>

1. Что такое ссылка

Ссылка (link, гиперссылка) — элемент, по клику на который браузер переходит на другой документ, другую часть страницы или запускает действие (звонок, письмо, скачивание).

Создаётся тегом <a> (от англ. anchor — «якорь»). Это парный тег, содержимым может быть текст, картинка, что угодно. 

<a href="https://example.com">Перейти на сайт</a>
Результат:
Перейти на сайт

Обязательный атрибут — href (hypertext reference). Без него ссылка не работает.

2. Абсолютные ссылки

Абсолютная ссылка содержит полный адрес, включая протокол (https://) и домен. 

<a href="https://developer.mozilla.org">MDN</a>
<a href="https://google.com">Google</a>
<a href="http://example.com/page">Пример</a>
Результат:
MDN · Google · Пример
Когда использовать: ссылки на внешние сайты. Всегда указывай полный адрес с протоколом.

Протоколы

Протокол Что означает
https:// Защищённый (современный стандарт)
http:// Незащищённый (устаревает)
//example.com Протокол-относительный: браузер подставит тот же, что у страницы

3. Относительные ссылки

Относительная ссылка — путь к файлу относительно текущего документа. Не содержит домена и протокола.

Представь такую структуру папок:

my-site/
├── index.html          ← мы здесь
├── about.html
├── contact.html
├── pages/
│   ├── blog.html
│   └── article.html
└── images/
    └── logo.png

Ссылки в той же папке

<a href="about.html">О нас</a>
<a href="contact.html">Контакты</a>

Ссылки во вложенной папке

<a href="pages/blog.html">Блог</a>
<a href="pages/article.html">Статья</a>

Ссылки на уровень выше (две точки)

Если файл находится во вложенной папке и нужно «подняться наверх»:

<!-- Из pages/blog.html на главную -->
<a href="../index.html">На главную</a>

<!-- Из pages/blog.html в папку images -->
<a href="../images/logo.png">Логотип</a>
Символ Значение
./ или ничего Текущая папка
../ Одна папка выше
../../ Две папки выше
/ Корень сайта (абсолютный путь от домена)
Совет: для локальной разработки используй относительные пути. Для публикации на сервере можно использовать пути от корня: /pages/blog.html.

4. Ссылки-якоря (внутри страницы)

Якорь — ссылка на определённое место внутри той же страницы. Используется символ # и id целевого элемента. 

<!-- Целевой элемент -->
<h2 id="pricing">Цены</h2>

<!-- Ссылка на него -->
<a href="#pricing">Перейти к ценам</a>
Результат (клик — прокрутка):
Перейти к разделу «Проверка» внизу страницы

Ссылка «вверх страницы»

Особый случай — ссылка на самое начало:

<a href="#">Вверх</a>   <!-- наверх (может добавить # в URL) -->
<a href="#">Вверх</a>   <!-- тоже наверх -->

Ссылка на якорь на другой странице

<a href="about.html#team">О нашей команде</a>

5. Атрибут target

Определяет, где открыть ссылку.

Значение Что делает
_self (по умолчанию) В текущей вкладке
_blank В новой вкладке
_parent В родительском фрейме
_top Во всём окне (выход из фреймов) 
<a href="https://example.com" target="_blank">Открыть в новой вкладке</a>
Результат:
Открыть в новой вкладке
Важно: при использовании target="_blank" обязательно добавляй rel="noopener noreferrer". Иначе открытая страница может управлять твоей через window.opener (угроза безопасности). 
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
    Безопасная внешняя ссылка
</a>

6. Атрибут rel — связь с ресурсом

rel описывает тип связи между текущим документом и целевым. Влияет на SEO и безопасность.

Значение Что означает
noopener Открытая страница не получает доступ к текущей (безопасность)
noreferrer Не передавать referer (информацию об источнике)
nofollow Поисковикам: не передавать вес ссылки
sponsored Это платная/рекламная ссылка
ugc Ссылка создана пользователем (UGC — user-generated content)
author Ссылка на автора документа
license Ссылка на лицензию
next, prev Следующая / предыдущая страница серии 
<!-- Внешняя ссылка в новой вкладке -->
<a href="https://example.com" target="_blank" rel="noopener noreferrer">...</a>

<!-- Рекламная ссылка -->
<a href="https://partner.com" rel="sponsored">Реклама</a>

<!-- Ссылка из комментариев -->
<a href="https://user-blog.com" rel="ugc">Блог автора</a>

7. Специальные ссылки: mailto, tel, sms

mailto — открыть почтовый клиент

<a href="mailto:info@example.com">Написать нам</a>

<!-- С темой и текстом -->
<a href="mailto:info@example.com?subject=Вопрос&body=Здравствуйте!">
    Написать письмо
</a>

tel — позвонить (на мобильных)

<a href="tel:+79001234567">+7 900 123-45-67</a>

sms

<a href="sms:+79001234567">Отправить SMS</a>

Другие полезные протоколы

Протокол Что откроет
mailto: Почтовый клиент
tel: Набор номера
sms: СМС
skype: Skype
whatsapp:// WhatsApp
tg:// Telegram
geo: Карты с координатами
Результат:
Написать нам · +7 900 123-45-67 · Отправить SMS

8. Скачивание файлов

Атрибут download заставляет браузер скачать файл, а не открыть его:

<a href="document.pdf" download>Скачать PDF</a>

<!-- С заданным именем файла -->
<a href="file.pdf" download="Инструкция.pdf">Скачать</a>
download работает только для того же домена. Для внешних ссылок браузер может проигнорировать атрибут.

9. Ссылка-картинка

Внутри <a> может быть не только текст, но и картинка:

<a href="https://example.com">
    <img src="logo.png" alt="Логотип" width="100">
</a>

10. Атрибут title — подсказка

<a href="https://example.com" title="Перейти на главную">Главная</a>
Результат (наведи — увидишь всплывающую подсказку):
Главная
Не полагайся на title: он не работает на мобильных и плохо воспринимается screen reader'ами. Если что-то важно — пиши в тексте ссылки.

11. Правила хорошей ссылки

Правило Плохо Хорошо
Текст описательный «Нажмите здесь» «Читайте инструкцию»
Не «голая» ссылка https://example.com/page Страница о нас
Понятно, что откроется PDF Скачать инструкцию (PDF, 2 МБ)
Внешняя ссылка помечена Пример Пример ↗ или target="_blank"
Почему важно: screen reader'ы часто выводят список всех ссылок на странице. Если все ссылки называются «здесь» — пользователь не поймёт, куда они ведут.

12. Полный список атрибутов <a>

Атрибут Обязательный? Значения Описание
href Да (обычно) URL, путь, mailto, tel, #id Адрес назначения
target Нет _self, _blank, _parent, _top Где открыть ссылку
rel Нет noopener, noreferrer, nofollow, sponsored, ugc и др. Связь с ресурсом
download Нет Имя файла или пусто Скачать, а не открыть
title Нет Текст Подсказка при наведении
hreflang Нет ru, en Язык целевой страницы
type Нет MIME-тип Тип ресурса

13. Частые ошибки

Ошибка Почему плохо
Забыть href Ссылка не работает
Пустой href="" Перезагружает текущую страницу
href="example.com" без протокола Браузер посчитает это относительным путём: example.com в текущей папке
target="_blank" без rel="noopener" Уязвимость через window.opener
«Нажмите здесь» как текст ссылки Плохо для a11y и SEO
<a> без текста Невидимая ссылка — плохо для доступности
Вкладывать <a> в <a> Невалидно: вложенные ссылки запрещены
Забыть & в mailto-параметрах Сломает URL: нужно &amp;

14. Практическое задание

Задание 1. «Все виды ссылок»

Создай файл 10-practice.html. Размести на странице:

  • Абсолютную ссылку на https://developer.mozilla.org.
  • Относительную ссылку на about.html (файла нет, но структура важна).
  • Ссылку-якорь на раздел этой же страницы (нужно добавить <h2 id="target">).
  • Ссылку mailto: на твой email.
  • Ссылку tel: на номер телефона.
  • Внешнюю ссылку с target="_blank" и rel="noopener noreferrer".

Задание 2. «Структура папок»

Создай структуру:

site/
├── index.html      ← ссылки на about, pages/blog, images/logo
├── about.html
├── pages/
│   └── blog.html   ← ссылки на ../../index, ../about
└── images/
    └── logo.png

Сделай по 3 ссылки из каждого файла. Проверь, что переходы работают.

Задание 3. «Внутренняя навигация»

  • Сделай страницу с 3 большими разделами (<h2 id="...">).
  • Вверху — список ссылок на каждый раздел.
  • Внизу каждого раздела — ссылка «↑ Наверх» (на #top или на первый id).

Задание 4. «Проверь ссылки»

  • Открой DevTools (F12), найди все <a> в этом уроке.
  • Посмотри, какие атрибуты у каждой ссылки.
  • Проверь консоль — нет ли ошибок загрузки.

Задание 5. «Сломай и почини»

  • Напиши <a href="example.com"> (без протокола) — открой, посмотри на URL в адресной строке.
  • Убери href совсем — стиль ссылки пропадёт.
  • Попробуй вложить одну ссылку в другую — посмотри в DevTools, как браузер перестроил DOM.

16. Что запомнить из урока

  • Ссылка создаётся тегом <a> с обязательным href.
  • Абсолютная ссылка — полный адрес с протоколом и доменом (для внешних сайтов).
  • Относительная — путь к файлу относительно текущего (для своих страниц).
  • ../ — на уровень выше, ./ — текущая, / — корень сайта.
  • Якорь #id — переход внутри страницы.
  • target="_blank" — новая вкладка, но обязательно с rel="noopener noreferrer".
  • rel: nofollow, sponsored, ugc — для SEO.
  • Специальные протоколы: mailto:, tel:, sms:.
  • download — скачать файл, а не открыть.
  • Текст ссылки должен быть описательным, а не «здесь» или «читать далее».
