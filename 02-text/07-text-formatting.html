Урок 7. Форматирование текста

1. Главная идея урока

Почти каждый тег форматирования существует в двух вариантах:

  • Смысловой (semantic) — говорит «это важно», «это акцент», «это удалено».
  • Визуальный (presentational) — говорит «сделай жирным», «сделай курсивом».

Внешне они могут выглядеть одинаково, но смысл у них разный. Поисковики и screen reader'ы реагируют только на смысловые теги.

Правило современного HTML: используй смысловые теги, когда есть смысл («важно», «акцент», «удалено»). Визуальные — только если смысла нет, а нужно просто «сделать курсивом». Но лучше для этого использовать CSS.

2. Теги «важности»: <strong> и <b>

Оба делают текст жирным, но по-разному.

Тег Смысл Как читает screen reader
<strong> Важность, серьёзность С изменением интонации («важно!»)
<b> Просто «выделить жирным» Обычно, без акцента 
<p>Это <strong>важное</strong> предупреждение.</p>
<p>А это просто <b>жирное</b> слово.</p>
Результат (выглядит одинаково, смысл разный):

Это важное предупреждение.

А это просто жирное слово.

Совет: используй <strong>, если текст действительно важен. <b> — редко, только для «стилистического» выделения без смысла (например, название бренда в тексте).

3. Теги акцента: <em> и <i>

Оба делают текст курсивом, но с разным смыслом.

Тег Смысл Пример
<em> Смысловой акцент (изменение интонации) «Я не говорил этого»
<i> Курсив без акцента: термины, названия, иностранные слова «Homo sapiens», «Titanic» 
<p>Я <em>не</em> хотел тебя обидеть.</p>
<p>Латинское название льва — <i>Panthera leo</i>.</p>
Результат:

Я не хотел тебя обидеть.

Латинское название льва — Panthera leo.

4. Тег <u> — подчёркивание

<u> (от англ. underline) — подчёркивает текст. Изначально — смысловой тег: «это аннотация, имя собственное в китайском, орфографическая ошибка». 

<p>Обратите внимание на <u>это слово</u>.</p>
Результат:

Обратите внимание на это слово.

Осторожно: на веб-страницах подчёркивание обычно означает ссылку. Если ты подчёркиваешь обычный текст, пользователь может попытаться по нему кликнуть. Используй <u> редко!

5. Тег <mark> — выделение маркером

<mark> выделяет текст как жёлтым маркером. Используется для подсветки релевантных частей — например, результатов поиска. 

<p>В результатах поиска слово <mark>HTML</mark> подсвечено.</p>
Результат:

В результатах поиска слово HTML подсвечено.

По умолчанию браузер красит фон в жёлтый. Цвет можно изменить через CSS:

<mark style="background: #b3e5fc; color: #01579b;">синее выделение</mark>
Результат:

синее выделение

6. Тег <small> — мелкий текст

<small> делает текст меньше. По смыслу — это «сноски, юридические примечания, копирайт». 

<p><small>© 2026 Все права защищены.</small></p>
Результат:

© 2026 Все права защищены.

7. Теги <del> и <ins> — удалено и вставлено

Пара тегов для показа правок в документе:

Тег Смысл Внешний вид по умолчанию
<del> Удалённый текст Зачёркнутый
<ins> Вставленный текст Подчёркнутый 
<p>Цена: <del>1500</del> <ins>1200</ins> руб.</p>
Результат:

Цена: 1500 1200 руб.

Часто для «зачёркнутого» текста без смысла правки используют <s>: 

<p>Старая цена: <s>1500 руб.</s></p>
Результат:

Старая цена: 1500 руб.

Разница: <del> — «это было в документе, но мы это удалили» (в контексте правок). <s> — «это устарело / больше не актуально».

8. Теги <sub> и <sup> — нижний и верхний индекс

Тег Что делает Пример
<sub> Нижний индекс H2O
<sup> Верхний индекс E = mc2 
<p>Формула воды: H<sub>2</sub>O</p>
<p>Уравнение: E = mc<sup>2</sup></p>
Результат:

Формула воды: H2O

Уравнение: E = mc2

10. Вложенность тегов форматирования

Теги можно комбинировать. Главное — правильный порядок закрытия.

<p>Это <strong>жирный <em>и курсивный</em></strong> текст.</p>
<p>Это <mark>выделенный <strong>важный</strong> фрагмент</mark>.</p>
Результат:

Это жирный и курсивный текст.

Это выделенный важный фрагмент.

11. Как браузер стилизует по умолчанию

Тег CSS по умолчанию
<strong>, <b> font-weight: bold
<em>, <i> font-style: italic
<u>, <ins> text-decoration: underline
<del>, <s> text-decoration: line-through
<mark> background: yellow; color: black
<small> font-size: smaller
<sub> vertical-align: sub; font-size: smaller
<sup> vertical-align: super; font-size: smaller

12. Частые ошибки

Ошибка Почему плохо
Использовать <b> вместо <strong> Теряется смысл «важности» для SEO и screen reader'ов
Подчёркивать текст через <u> без смысла Пользователи думают, что это ссылка
Пересекать теги: <strong><em>...</strong></em> Невалидно, браузер может перестроить
Использовать <mark> для декора Это смысловая подсветка, а не «красивый фон»
Вкладывать блочные теги в форматирующие <strong><div>...</div></strong> — нельзя

13. Практическое задание

Задание 1. «Текст с выделениями»

Создай файл 07-practice.html. Напиши 3–4 абзаца на любую тему, используя:

  • <strong> — минимум 2 раза
  • <em> — минимум 2 раза
  • <mark> — 1 раз
  • <small> — 1 раз (копирайт внизу)
  • <del> + <ins> — «старая цена → новая»

Задание 2. «Формулы»

  • Напиши формулу воды через <sub>: H2O
  • Напиши формулу Эйнштейна через <sup>: E = mc2
  • Напиши квадратный корень: √x через <sup>

Задание 3. «Сравни b/strong и i/em»

  • Сделай два параграфа: в одном <b> и <i>, в другом <strong> и <em>.
  • Открой DevTools (F12) → Elements → найди эти теги.
  • Убедись, что браузер показывает их по-разному (разные теги в DOM).

Задание 4. «Сломай и почини»

  • Пересеки теги: <strong><em>текст</strong></em>. Посмотри, что сделает браузер.
  • Подчеркни текст через <u> и наведи — выглядит как ссылка? Подумай, стоит ли так делать.
  • Сделай <mark> с другим цветом через CSS: style="background: #ffcdd2;".

14. Что запомнить из урока

  • Смысл vs вид: <strong> (важно) vs <b> (просто жирный).
  • <em> — акцент, <i> — курсив для терминов и названий.
  • <mark> — подсветка релевантного (как в поиске).
  • <small> — сноски и копирайт.
  • <del> / <ins> — правки в документе (удалено / вставлено).
  • <s> — устаревшее, неактуальное.
  • <sub> / <sup> — химия и математика.
  • Правило выбора: если есть смысл — используй смысловой тег. Если только вид — лучше CSS.
  • Теги форматирования — строчные (inline), их можно вкладывать друг в друга и в текст.
  • Теги можно пересекать? Нет. Закрывай в обратном порядке.
