Урок 6. Параграфы, переносы и горизонтальная линия

1. Общая картина

В этом уроке — три тега, которые ты будешь использовать постоянно:

Тег Что делает Тип
<p> Параграф (абзац текста) Парный
<br> Перенос строки внутри текста Одиночный
<hr> Горизонтальная линия (разделитель) Одиночный

2. Тег <p> — параграф

Параграф (от англ. paragraph) — это логически завершённый блок текста. Мысль, абзац, фрагмент. Основная «единица» текстового контента. 

<p>Это первый параграф. Он содержит одну законченную мысль.</p>
<p>А это второй параграф. У него уже другая мысль.</p>
Результат:

Это первый параграф. Он содержит одну законченную мысль.

А это второй параграф. У него уже другая мысль.

Ключевые свойства <p>

  • Это блочный тег — занимает всю ширину, начинается с новой строки.
  • Браузер автоматически добавляет отступы сверху и снизу (margin).
  • Два соседних параграфа визуально разделяются пустым пространством.
  • Внутри может быть текст и фразовые теги: <strong>, <em>, <a>, <code>, <span>.
Нельзя вкладывать в <p> блочные теги: <div>, <h1>, <ul>, <table>, другой <p>. Браузер автоматически «закроет» параграф перед таким тегом, что сломает структуру.

Как браузер схлопывает пробелы

Важное правило HTML: лишние пробелы и переносы строк игнорируются.

<p>
    Это      предложение      с      большим      количеством      пробелов.


    И даже с переносами строк.
</p>
Результат (всё схлопнулось в один абзац):

Это предложение с большим количеством пробелов. И даже с переносами строк.

Правило: подряд идущие пробелы, табы и переносы строк браузер превращает в один пробел. Так HTML позволяет писать код красиво, не думая о форматировании.

3. Тег <br> — перенос строки

<br> (от англ. break — «разрыв») — одиночный тег. Он заставляет браузер перейти на новую строку внутри одного блочного элемента. 

<p>
    Строка первая.<br>
    Строка вторая.<br>
    Строка третья.
</p>
Результат:

Строка первая.
Строка вторая.
Строка третья.

Когда использовать <br>

  • Адрес в несколько строк.
  • Стихи — каждая строка отдельно.
  • Подпись под картинкой в несколько строк.
  • Короткие фразы, где перенос важен по смыслу.
<p>
    Иван Иванов<br>
    ул. Пушкина, д. 10<br>
    Москва, 101000
</p>

Когда <br> использовать НЕЛЬЗЯ

Главная ошибка новичков: использовать <br><br> для создания отступов между абзацами. Для этого есть <p> и CSS! 
<!-- ПЛОХО: имитация абзацев через br -->
<p>Первый абзац.<br><br>
Второй абзац.<br><br>
Третий абзац.</p>

<!-- ХОРОШО: настоящие параграфы -->
<p>Первый абзац.</p>
<p>Второй абзац.</p>
<p>Третий абзац.</p>

Почему «плохо»: ломается семантика, screen reader'ы не делают паузы, поисковики не понимают структуру.

4. Тег <hr> — горизонтальная линия

<hr> (от англ. horizontal rule — «горизонтальная линейка») — одиночный тег. Рисует горизонтальную линию через всю ширину родителя. 

<p>Первый раздел.</p>
<hr>
<p>Второй раздел.</p>
Результат:

Первый раздел.

Второй раздел.

Семантика <hr>

Важно: <hr> — это не просто линия, а смысловой разделитель: «здесь заканчивается одна тема и начинается другая». Например, переход между главами, смена сцены, разделение блоков контента.

Не используй <hr> просто «чтобы была линия» для красоты. Для декоративных линий есть CSS (border, background). <hr> — только там, где по смыслу нужен разделитель.

Внешний вид

По умолчанию браузер рисует <hr> как тонкую серую линию с отступами сверху и снизу. Стиль полностью настраивается через CSS:

<hr style="border: none; border-top: 2px dashed #b5651d;">

5. Сравнение: <p> vs <br> vs <hr>

Что нужно Тег
Новый абзац текста <p>
Перенос строки внутри абзаца (адрес, стихи) <br>
Пустое пространство между абзацами <p> (по умолчанию) или CSS margin
Смысловой разделитель между темами <hr>
Декоративная линия для красоты CSS (border-bottom)

6. Полный пример страницы

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя статья</title>
</head>
<body>
    <h1>Как варить кофе</h1>

    <p>Кофе — это напиток, который любят миллионы людей.</p>
    <p>Но не все умеют его правильно готовить.</p>

    <hr>

    <h2>Ингредиенты</h2>
    <p>Вам понадобится:</p>
    <p>
        Кофе в зёрнах<br>
        Вода<br>
        Кофемолка<br>
        Турка
    </p>

    <hr>

    <h2>Приготовление</h2>
    <p>Смешайте кофе с водой и варите на медленном огне.</p>
    <p>Готово!</p>
</body>
</html>

7. Частые ошибки

Ошибка Почему плохо
Использовать <br><br> вместо нового <p> Ломает семантику, screen reader'ы не делают пауз
Вкладывать <div> внутрь <p> Невалидно, браузер сам «закроет» параграф
Вкладывать <p> внутрь <p> Невалидно: параграф нельзя вкладывать в параграф
Использовать <hr> для красоты Линия без смысла = лишний тег. Для декора — CSS
Закрывать <br></br> Нельзя: <br> — одиночный тег
Закрывать <hr></hr> То же самое: <hr> одиночный
Пытаться создать отступ через пустые <p></p> Пустые параграфы игнорируются браузером, используй CSS

8. Как браузер стилизует по умолчанию

  • <p> — отступ сверху и снизу примерно 1em, никаких других стилей.
  • <br> — просто перенос, без стилей.
  • <hr> — линия шириной 1px, отступы ~0.5em сверху и снизу, цвет серый.

9. Практическое задание

Задание 1. «Статья»

Создай файл 06-practice.html. Напиши короткую статью о своём хобби:

  • <h1> — название статьи.
  • 3–4 <p> — основные абзацы текста.
  • Один <hr> — разделитель между введением и основной частью.
  • Один абзац с <br> — например, список инвентаря или адрес.

Задание 2. «Проверка схлопывания»

  • Напиши один параграф с большим количеством пробелов и переносов внутри.
  • Открой в браузере — увидишь, что всё схлопнулось в один пробел.
  • Теперь сделай то же в <pre> — увидишь разницу.

Задание 3. «Стилизация hr»

  • Сделай <hr> пунктирной линией: style="border: none; border-top: 2px dashed red;".
  • Попробуй сделать толстую цветную линию через border-top: 5px solid green;.
  • Убери линию совсем: border: none;.

Задание 4. «Сломай и почини»

  • Вложи <div> в <p>. Открой в браузере, посмотри исходник — браузер сам перестроит структуру.
  • Вложи <p> в <p>. Тот же результат.
  • Сделай «отступы» через <br><br>. Убедись, что это выглядит хуже, чем <p>.

10. Что запомнить из урока

  • <p> — параграф, блочный тег, основная единица текста.
  • Внутри <p> — только текст и фразовые теги, никаких блочных.
  • Лишние пробелы и переносы строк браузер схлопывает в один пробел.
  • <br> — перенос строки внутри блока (адрес, стихи). Не для отступов!
  • <hr> — смысловой разделитель между темами, а не декоративная линия.
  • <br> и <hr> — одиночные теги, у них нет закрывающей части.
  • Для отступов и линий «для красоты» используй CSS, а не HTML-теги.
