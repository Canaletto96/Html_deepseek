Урок 14. Встраивание контента

1. Что такое встраивание

Иногда нужно показать на странице чужой контент: видео с YouTube, карту из Google Maps, пост из Telegram, оплату из Stripe.

Можно либо скопировать этот контент к себе (невозможно для интерактива), либо встроить чужую страницу прямо в свою. Для второго есть три тега:

Тег Для чего Когда использовать
<iframe> Встроить целую HTML-страницу 99% случаев — YouTube, карты, виджеты
<embed> Встроить внешний ресурс (PDF, Flash когда-то) Редко: PDF, SVG
<object> Универсальный контейнер Почти устарел, для PDF иногда
Правило: если сомневаешься — используй <iframe>. Остальные два — редкость в современном вебе.

2. Тег <iframe> — окно в другую страницу

<iframe> (inline frame) — «рамка внутри страницы». Загружает другую HTML-страницу в прямоугольную область. 

<iframe src="https://example.com" width="600" height="400"></iframe>
Результат:

Атрибуты <iframe>

Атрибут Значения Описание
src URL Адрес встраиваемой страницы
width / height Число (px) или % Размеры окна
title Текст Обязателен для доступности! Описание содержимого
loading eager, lazy Ленивая загрузка
allow Разрешения Что можно встроенной странице (камера, микрофон и т.д.)
allowfullscreen булев Разрешить полноэкранный режим
sandbox Флаги безопасности Ограничения для встроенного контента
referrerpolicy no-referrer и др. Что передавать в referer
srcdoc HTML-код Вставить HTML напрямую, а не URL
Обязательно указывай title. Screen reader'ы читают его, чтобы пользователь понял, что внутри рамки. Без title — плохо для доступности.

3. Встраивание YouTube

Самый частый случай. На любом видео YouTube есть кнопка «Поделиться» → «Встроить». Ты получаешь готовый код: 

<iframe width="560" height="315"
        src="https://www.youtube.com/embed/VIDEO_ID"
        title="YouTube video player"
        frameborder="0"
        allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
        allowfullscreen>
</iframe>

Разбор:

  • VIDEO_ID — идентификатор видео (например, dQw4w9WgXcQ).
  • allowfullscreen — кнопка «на весь экран».
  • allow — список разрешений (autoplay, микрофон и т.д.).

4. Встраивание Google Maps

На Google Maps: найди место → «Поделиться» → «Встроить карту». Получишь код: 

<iframe src="https://www.google.com/maps/embed?pb=..."
        width="600" height="450" style="border:0;"
        allowfullscreen=""
        loading="lazy"
        referrerpolicy="no-referrer-when-downgrade"
        title="Карта: Москва">
</iframe>
Совет: для карт всегда используй loading="lazy" — карты тяжёлые, не нужно грузить их сразу.

6. Атрибут sandbox — безопасность

sandbox — песочница. Ограничивает, что может делать встроенная страница. По умолчанию (если указать пустой sandbox="") запрещено всё.

Чтобы что-то разрешить, добавляй флаги:

Флаг Что разрешает
allow-scripts Выполнять JavaScript
allow-forms Отправлять формы
allow-same-origin Считать контент «своим» доменом
allow-popups Открывать новые окна
allow-modals Alert, confirm, prompt
allow-top-navigation Управлять URL верхнего окна
allow-downloads Скачивать файлы 
<iframe src="untrusted.html"
        sandbox="allow-scripts allow-forms"
        title="Форма обратной связи">
</iframe>
Осторожно: allow-scripts + allow-same-origin вместе — опасная комбинация. Встроенная страница сможет делать почти всё, что хочет, включая доступ к cookies твоего сайта. Не используй для недоверенного контента.

7. Атрибут allow — разрешения

allow управляет доступом к API браузера:

Значение Что разрешает
autoplay Автовоспроизведение медиа
camera Доступ к камере
microphone Доступ к микрофону
geolocation Геолокация
fullscreen Полноэкранный режим
clipboard-write Запись в буфер обмена
picture-in-picture Картинка-в-картинке (видео) 
<iframe src="video.html"
        allow="autoplay; fullscreen; picture-in-picture"
        allowfullscreen
        title="Видео">
</iframe>

8. Ленивая загрузка iframe

loading="lazy" откладывает загрузку, пока пользователь не приблизится: 

<iframe src="https://www.youtube.com/embed/VIDEO_ID"
        width="560" height="315"
        loading="lazy"
        title="Видео"
        allowfullscreen>
</iframe>

Обязательно для карт, видео, виджетов — они тяжёлые. Для критичного контента первого экрана — оставляй eager.

9. Тег <embed>

<embed> — одиночный тег для встраивания внешнего ресурса: PDF, SVG, аудио, видео. 

<embed src="document.pdf" type="application/pdf" width="600" height="400">
Атрибут Значения Описание
src URL Адрес ресурса
type MIME-тип application/pdf, image/svg+xml и др.
width / height Число (px) Размеры
Когда использовать embed: почти никогда. Для PDF лучше <iframe>, для SVG — <img>, для видео — <video>. Embed — легаси-тег.

10. Тег <object>

<object> — универсальный контейнер. Парный тег, может содержать fallback-контент. 

<object data="document.pdf" type="application/pdf" width="600" height="400">
    <p>Ваш браузер не поддерживает PDF.
       <a href="document.pdf">Скачать файл</a>.</p>
</object>
Атрибут Описание
data URL ресурса (аналог src)
type MIME-тип
width / height Размеры
name Имя для доступа из JavaScript

11. Сравнение трёх тегов

<iframe> <embed> <object>
Для HTML-страниц ✅ Да ❌ Нет ❌ Нет
Fallback-контент ✅ Да (между тегами) ❌ Нет ✅ Да
Песочница (sandbox) ✅ Да ❌ Нет ❌ Нет
Актуальность Основной Легаси Легаси

12. Проблемы и ограничения iframe

1. Некоторые сайты запрещают встраивание

Через заголовок X-Frame-Options: DENY или Content-Security-Policy: frame-ancestors 'none' сайт может запретить встраивание. Ты увидишь пустую рамку или сообщение об ошибке.

2. Медленная загрузка

iframe грузит всю встроенную страницу — со всеми её ресурсами. Решение — loading="lazy".

3. Сложно стилизовать содержимое

CSS твоей страницы не работает внутри iframe — там свой документ. Изменить оформление чужого сайта нельзя (это и хорошо для безопасности).

4. SEO

Поисковики плохо индексируют контент внутри iframe. Не используй для основного содержимого.

5. Уязвимости

  • Clickjacking — злоумышленник накладывает невидимый iframe поверх кнопки на твоём сайте.
  • XSS через iframe — если встроить недоверенный контент без sandbox.
  • Утечка через window.opener — если открыть iframe в новом окне без noopener.
Защита: всегда используй sandbox для недоверенного контента, referrerpolicy для контроля referer, allow для точных разрешений.

13. Частые ошибки

Ошибка Почему плохо
Забыть title Плохо для screen reader'ов
Не использовать loading="lazy" для карт/видео Тормозит загрузку страницы
Встраивать недоверенный контент без sandbox Уязвимости XSS
Использовать iframe для основного контента Плохо для SEO и доступности
Указывать только width без height Прыжки контента при загрузке
Забыть allowfullscreen для видео Пользователь не сможет развернуть на весь экран

14. Готовые шаблоны

YouTube (ленивая загрузка)

<iframe width="560" height="315"
        src="https://www.youtube.com/embed/VIDEO_ID"
        title="Описание видео"
        loading="lazy"
        frameborder="0"
        allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
        allowfullscreen>
</iframe>

Google Maps

<iframe src="https://www.google.com/maps/embed?pb=..."
        width="600" height="450"
        style="border:0;"
        allowfullscreen=""
        loading="lazy"
        referrerpolicy="no-referrer-when-downgrade"
        title="Карта">
</iframe>

Адаптивный iframe (16:9)

<div style="position: relative; padding-bottom: 56.25%; height: 0; overflow: hidden;">
    <iframe src="https://www.youtube.com/embed/VIDEO_ID"
            style="position: absolute; top:0; left:0; width:100%; height:100%;"
            title="Видео"
            frameborder="0"
            allowfullscreen>
    </iframe>
</div>

Это классический приём для адаптивных видео — они растягиваются по ширине контейнера, сохраняя пропорции 16:9.

15. Практическое задание

Задание 1. «Простой iframe»

Создай файл 14-practice.html. Вставь:

  • iframe с сайтом https://example.com (600×400).
  • Не забудь title.

Задание 2. «YouTube»

  • Найди на YouTube любое видео, скопируй код встраивания.
  • Добавь loading="lazy" к этому iframe.

Задание 3. «Адаптивное видео»

  • Оберни iframe в <div> с padding-bottom: 56.25%.
  • Проверь, что при сужении окна видео уменьшается, сохраняя пропорции 16:9.

Задание 4. «Карта»

  • Открой Google Maps, найди свой город.
  • «Поделиться» → «Встроить карту» → скопируй код.
  • Вставь на страницу с loading="lazy".

Задание 5. «Сломай и почини»

  • Попробуй встроить https://google.com — увидишь отказ (заголовок X-Frame-Options).
  • Добавь sandbox="" (пустой) — увидишь, что внутри iframe перестало работать.
  • Убери title — проверь через валидатор, увидишь предупреждение.

16. Что запомнить из урока

  • <iframe> — основной тег для встраивания. 99% случаев — он.
  • <embed> и <object> — легаси, использовать почти не нужно.
  • Для YouTube, карт, виджетов — всегда loading="lazy".
  • Обязательно добавляй title — для screen reader'ов.
  • allowfullscreen — для видео, чтобы можно было развернуть.
  • allow — список разрешений (autoplay, camera, microphone и т.д.).
  • sandbox — песочница для безопасности. Обязательна для недоверенного контента.
  • Некоторые сайты запрещают встраивание (X-Frame-Options).
  • CSS твоей страницы не работает внутри iframe.
  • Адаптивное видео: обёртка с padding-bottom: 56.25% + iframe с абсолютным позиционированием.
