Урок 13. Аудио и видео

1. Что было раньше и что стало

До HTML5 для встраивания видео и аудио нужны были плагины (Flash, Silverlight) или тег <object>. Это было неудобно: работало не везде, требовало установки плагинов.

В HTML5 появились нативные теги <audio> и <video>. Браузер воспроизводит их сам, без плагинов.

2. Тег <audio>

Для звука — музыка, подкасты, звуковые эффекты.

<audio controls>
    <source src="music.mp3" type="audio/mpeg">
    <source src="music.ogg" type="audio/ogg">
    Ваш браузер не поддерживает аудио.
</audio>

Браузер сам рисует панель управления: play/pause, громкость, прогресс. Это возможно благодаря атрибуту controls.

3. Тег <video>

Для видео — фильмы, ролики, анимации.

<video controls width="640" height="360">
    <source src="movie.mp4" type="video/mp4">
    <source src="movie.webm" type="video/webm">
    Ваш браузер не поддерживает видео.
</video>

4. Атрибуты <audio> и <video>

Большинство атрибутов — общие для обоих тегов.

Атрибут Значения Что делает
controls булев Показать панель управления (play, pause, громкость)
autoplay булев Начать воспроизведение автоматически
loop булев Повторять бесконечно
muted булев Начать без звука
preload none, metadata, auto Что загружать заранее
src URL Источник (если не используется <source>)
poster URL картинки Превью до начала воспроизведения (только video)
width / height Число (px) Размеры (только video)
playsinline булев Не открывать на весь экран на мобильных (только video)
Важно про autoplay: современные браузеры запрещают автозапуск со звуком. Чтобы autoplay сработал, нужно добавить muted. Это борьба с навязчивыми сайтами. 
<video autoplay muted loop controls>
    <source src="movie.mp4" type="video/mp4">
</video>

5. Тег <source> — несколько форматов

Разные браузеры поддерживают разные форматы. Тег <source> позволяет указать несколько версий одного медиа — браузер сам выберет поддерживаемую. 

<video controls>
    <source src="movie.webm" type="video/webm">
    <source src="movie.mp4" type="video/mp4">
    <source src="movie.ogv" type="video/ogg">
    Ваш браузер не поддерживает видео.
</video>

Порядок важен: браузер берёт первый поддерживаемый формат. Ставь сверху более эффективные (WebM), снизу — универсальные (MP4).

6. Форматы аудио

Формат MIME-тип Поддержка
MP3 audio/mpeg Везде. Универсальный.
OGG audio/ogg Firefox, Chrome, Opera
WAV audio/wav Везде, но огромный размер
AAC / M4A audio/aac, audio/mp4 Все современные браузеры, лучше MP3 по качеству/размеру
FLAC audio/flac Без потерь, но тяжелее

7. Форматы видео

Формат MIME-тип Поддержка
MP4 (H.264) video/mp4 Везде. Универсальный стандарт.
WebM video/webm Chrome, Firefox, Edge, Opera. Меньше размер.
OGG video/ogg Firefox, Chrome, Opera
MP4 (H.265/HEVC) video/mp4 Лучше качество, но не везде поддерживается
AV1 video/mp4 или video/webm Новейший, отличное сжатие, поддержка растёт
Практический совет: для веба используй MP4 (H.264) как основной и WebM как альтернативу. MP4 работает везде.

8. Тег <track> — субтитры

<track> подключает текстовую дорожку: субтитры, титры, описания. Формат файла — WebVTT (.vtt). 

<video controls>
    <source src="movie.mp4" type="video/mp4">
    <track src="subtitles-ru.vtt" kind="subtitles" srclang="ru" label="Русские">
    <track src="subtitles-en.vtt" kind="subtitles" srclang="en" label="English">
</video>

Атрибуты <track>

Атрибут Значения Что делает
src URL .vtt файла Путь к дорожке
kind subtitles, captions, descriptions, chapters, metadata Тип дорожки
srclang Код языка: ru, en Язык дорожки
label Текст Название в меню плеера
default булев Включить эту дорожку по умолчанию

Пример файла .vtt

WEBVTT

00:00:00.000 --> 00:00:03.000
Привет! Это первая строка субтитров.

00:00:03.000 --> 00:00:06.000
А это вторая.
Формат WebVTT: начинается с WEBVTT, потом блоки с временем и текстом. Время в формате ЧЧ:ММ:СС.ммм.

9. Атрибут poster — превью для видео

Пока видео не запущено, браузер показывает либо первый кадр, либо пустоту. Атрибут poster задаёт картинку-превью. 

<video controls poster="preview.jpg" width="640">
    <source src="movie.mp4" type="video/mp4">
</video>

10. Фоновое видео (autoplay + muted + loop)

Классический приём на лендингах: видео играет в фоне без звука и панели управления. 

<video autoplay muted loop playsinline
       style="width: 100%; height: auto;">
    <source src="background.mp4" type="video/mp4">
</video>

11. Что делать, если браузер не поддерживает

Текст внутри <audio> или <video>, который не является <source> или <track>, показывается как запасной вариант: 

<video controls>
    <source src="movie.mp4" type="video/mp4">
    <p>Ваш браузер не поддерживает видео.
       <a href="movie.mp4">Скачать файл</a>.</p>
</video>

Современные браузеры это показывают редко, но для старых — полезно.

12. Частые ошибки

Ошибка Почему плохо
Забыть controls Пользователь не сможет запустить воспроизведение
autoplay без muted Браузер заблокирует автозапуск
Только MP4 без WebM Работает, но размер файла больше. WebM эффективнее
Указывать src в теге и в <source> одновременно Дублирование, лучше выбрать что-то одно
Забыть про субтитры Плохо для доступности (a11y) и SEO
Тяжёлые видео без сжатия Долгая загрузка, плохой UX
Нет poster на видео Пользователь видит чёрный или случайный кадр

13. Полезные комбинации

Аудио с несколькими форматами

<audio controls preload="metadata">
    <source src="podcast.m4a" type="audio/mp4">
    <source src="podcast.mp3" type="audio/mpeg">
    <source src="podcast.ogg" type="audio/ogg">
    Ваш браузер не поддерживает аудио.
</audio>

Видео с превью и субтитрами

<video controls width="640" height="360"
       poster="preview.jpg" preload="metadata">
    <source src="movie.webm" type="video/webm">
    <source src="movie.mp4" type="video/mp4">
    <track src="subs-ru.vtt" kind="subtitles" srclang="ru" label="Русский" default>
    <track src="subs-en.vtt" kind="subtitles" srclang="en" label="English">
    Ваш браузер не поддерживает видео.
</video>

Фоновое видео на лендинге

<video autoplay muted loop playsinline
       style="position: fixed; top: 0; left: 0; width: 100%; height: 100%; object-fit: cover; z-index: -1;">
    <source src="bg.mp4" type="video/mp4">
</video>

14. Практическое задание

Задание 1. «Аудиоплеер»

Создай файл 13-practice.html. Размести на странице:

  • <audio controls> с одним источником (можно использовать публичный URL).
  • Второй <audio> с двумя <source> (mp3 + ogg).
  • Третий <audio> с loop — зацикленный звук.

Задание 2. «Видеоплеер»

  • <video controls> с width="640" и poster.
  • Добавь два формата: .mp4 и .webm.
  • Проверь через DevTools → Network, какой формат загрузился.

Задание 3. «Фоновое видео»

  • Сделай блок с <video autoplay muted loop playsinline>.
  • Добавь CSS: width: 100%; height: 500px; object-fit: cover;.
  • Убедись, что видео занимает весь блок.

Задание 4. «Субтитры»

  • Создай файл subs-ru.vtt рядом с HTML.
  • Напиши 3–4 строки субтитров в формате WebVTT.
  • Подключи через <track> к видео.
  • Включи субтитры в плеере — проверь, что работают.

Задание 5. «Сломай и почини»

  • Убери controls — увидишь «немой» плеер без элементов управления.
  • Убери muted у autoplay — браузер не запустит видео.
  • Укажи несуществующий путь к файлу — увидишь alt-текст или пустое место.

15. Что запомнить из урока

  • <audio> — для звука, <video> — для видео. Оба нативные.
  • Обязательно добавляй controls — иначе пользователь ничего не запустит.
  • autoplay работает только с muted (защита браузеров).
  • loop — зацикливание, preload — что грузить заранее.
  • <source> — несколько форматов, браузер выберет поддерживаемый.
  • Для видео: MP4 (H.264) — универсальный, WebM — эффективнее.
  • Для аудио: MP3 — универсальный, M4A/AAC — качественнее.
  • poster — превью для видео (картинка до запуска).
  • <track> — субтитры в формате WebVTT (.vtt).
  • Для фонового видео: autoplay muted loop playsinline + CSS.
