Урок 11. Изображения <img>

1. Что такое <img>

<img> (от англ. image) — одиночный тег для вставки изображения. У него нет закрывающей части, потому что внутри ничего не может быть. 

<img src="cat.jpg" alt="Рыжий кот">

Минимум для работы — два атрибута: src (что показать) и alt (что это).

2. Атрибут src — источник изображения

src (source) — путь к файлу изображения. Может быть:

Тип пути Пример Когда использовать
Относительный cat.jpg, ../images/cat.jpg Свои картинки на сайте
Абсолютный от корня /images/cat.jpg На сервере с известной структурой
Полный URL https://example.com/cat.jpg Чужие картинки (с разрешения!)
Data URI data:image/png;base64,... Маленькие иконки прямо в коде 
<img src="cat.jpg" alt="Рыжий кот">
<img src="../images/cat.jpg" alt="Рыжий кот">
<img src="/images/cat.jpg" alt="Рыжий кот">
<img src="https://example.com/cat.jpg" alt="Рыжий кот">

3. Атрибут alt — альтернативный текст

Обязательный атрибут. Показывается, если картинка не загрузилась. Читается screen reader'ами. Индексируется поисковиками. 

<img src="cat.jpg" alt="Рыжий кот спит на подоконнике">

Что будет без alt

Правила хорошего alt

Ситуация Что писать в alt
Смысловая картинка (фото, схема) Описание содержания: «Кот спит на подоконнике»
Декоративная картинка (фон, разделитель) alt="" (пусто — screen reader пропустит)
Картинка-ссылка Куда ведёт: «Перейти на главную»
Кнопка-иконка Действие: «Отправить форму», «Открыть меню»
Логотип в шапке «Логотип компании Мурлыка»
Плохой alt:
  • alt="картинка" — не описывает содержание
  • alt="img123.jpg" — имя файла бесполезно
  • Отсутствие alt — screen reader прочитает URL
  • Длинная простыня — alt должен быть кратким

4. Атрибуты width и height

Задают размеры изображения в пикселях (без единиц измерения).

<img src="cat.jpg" alt="Кот" width="400" height="300">

Зачем указывать размеры

Главная причина — избежать «прыжков» страницы. Пока картинка грузится, браузер не знает её размеры. Если width и height не указаны, при загрузке контент резко сдвинется вниз — это называется layout shift (CLS). Плохо для UX и SEO.

Как правильно

  • Указывай реальные размеры картинки (её исходные).
  • Для уменьшения на странице — используй CSS (max-width: 100%), а не атрибуты.
  • Не искажай пропорции: либо указывай оба атрибута, либо не указывай совсем.
<!-- ХОРОШО: реальные размеры + CSS для адаптивности -->
<img src="cat.jpg" alt="Кот" width="800" height="600" style="max-width: 100%; height: auto;">
Не указывай только один из размеров — браузер не сможет рассчитать пропорции и сдвинет контент. Указывай оба или ни одного.

5. Форматы изображений

Формат Расширение Особенности
JPEG .jpg, .jpeg Фото, сжатие с потерей качества, без прозрачности
PNG .png Логотипы, иконки, прозрачность, сжатие без потерь
GIF .gif Анимация, ограничение 256 цветов (устарел)
SVG .svg Векторные иконки, масштабируются без потерь
WebP .webp Современный: меньше размер, поддержка прозрачности и анимации
AVIF .avif Новейший: ещё лучше сжатие, но не везде поддерживается

6. srcset и sizes — адаптивные изображения

Для разных экранов (мобильный, планшет, retina) можно указать несколько версий одной картинки. Браузер сам выберет подходящую. 

<img src="cat-800.jpg"
     srcset="cat-400.jpg 400w,
             cat-800.jpg 800w,
             cat-1600.jpg 1600w"
     sizes="(max-width: 600px) 100vw, 800px"
     alt="Кот">

Как это работает:

  • srcset — список версий с указанием ширины (400w = 400px ширины).
  • sizes — какую ширину занимает картинка на разных экранах.
  • Браузер сам подберёт оптимальный вариант.
Для новичков: пока можно не использовать srcset — достаточно width, height и CSS max-width: 100%. Но знать про него полезно.

7. Атрибут loading — ленивая загрузка

loading управляет моментом загрузки изображения:

Значение Что делает
eager (по умолчанию) Загрузить сразу
lazy Загрузить, когда пользователь приблизится к картинке 
<!-- Первый экран — загружать сразу -->
<img src="hero.jpg" alt="Главный баннер" loading="eager">

<!-- Ниже — ленивая загрузка -->
<img src="photo1.jpg" alt="Фото 1" loading="lazy">
<img src="photo2.jpg" alt="Фото 2" loading="lazy">
Правило: loading="lazy" — для картинок ниже первого экрана. Для главных баннеров и логотипов — оставляй по умолчанию (eager), иначе первый экран будет пустым.

8. Полный список атрибутов <img>

Атрибут Обязательный? Значения Описание
src Да URL / путь Источник изображения
alt Да (по правилам) Текст или "" Альтернативный текст
width Нет Число (px) Ширина
height Нет Число (px) Высота
srcset Нет Список URL с дескрипторами Адаптивные версии
sizes Нет Медиа-запросы Размеры для srcset
loading Нет eager, lazy Момент загрузки
decoding Нет sync, async, auto Как декодировать
crossorigin Нет anonymous, use-credentials Настройки CORS
usemap Нет #имя Карта изображения
ismap Нет булев Серверная карта
referrerpolicy Нет no-referrer, origin и др. Что передавать в referer

9. Изображение как ссылка

Картинку можно обернуть в <a>, чтобы она стала кликабельной:

<a href="https://example.com">
    <img src="logo.png" alt="Перейти на главную" width="120">
</a>
Важно: в alt картинки-ссылки пиши куда ведёт, а не что изображено. Screen reader читает именно alt.

10. Частые ошибки

Ошибка Почему плохо
Забыть alt Ломает доступность, screen reader читает URL
alt="картинка", alt="img.jpg" Бесполезно для незрячих
Указывать только width или только height Прыжки контента при загрузке, искажение пропорций
Растягивать картинку меньше её реального размера через атрибуты Плохое качество. Лучше сделать уменьшенную версию или использовать CSS
Вставлять чужие картинки без разрешения Нарушение авторских прав
Использовать <img> вместо фона Для декоративных фонов — CSS background-image
Огромные картинки в оригинальном размере Долгая загрузка. Сжимай через TinyPNG, Squoosh
<img></img> Нельзя: <img> одиночный тег

11. Готовые шаблоны

Обычная картинка в статье

<img src="cat.jpg" alt="Рыжий кот спит на подоконнике" width="800" height="600">

Адаптивная картинка

<img src="cat.jpg" alt="Рыжий кот" width="800" height="600"
     style="max-width: 100%; height: auto;">

Картинка-ссылка

<a href="/">
    <img src="logo.png" alt="На главную" width="120" height="40">
</a>

С ленивой загрузкой

<img src="photo.jpg" alt="Пейзаж" width="800" height="600" loading="lazy">

Декоративная картинка (не важна)

<img src="decorative-line.png" alt="">

12. Практическое задание

Задание 1. «Пять изображений»

Создай файл 11-practice.html и папку images/ рядом с ним. Скачай 3–5 картинок (можно с Unsplash или Pexels) и размести их:

  • Первая — обычная с alt, width, height.
  • Вторая — адаптивная (с style="max-width: 100%; height: auto;").
  • Третья — обёрнутая в <a href="...">.
  • Четвёртая — с loading="lazy".
  • Пятая — декоративная с alt="".

Задание 2. «Alt-тексты»

  • Возьми одну картинку и напиши к ней 3 варианта alt: хороший, плохой, отличный.
  • Открой файл в браузере, сломай путь к картинке (src="wrong.jpg") — увидишь, что покажет браузер вместо картинки.

Задание 3. «Прыжки страницы»

  • Сделай страницу с 5 картинками без width/height.
  • Открой DevTools → Network → поставь «Slow 3G».
  • Обнови страницу — увидишь, как контент прыгает.
  • Добавь размеры, повтори — прыжков нет.

Задание 4. «Сломай и почини»

  • Убери alt — открой в браузере со сломанным путём.
  • Укажи только width="200" — посмотри, что будет с пропорциями.
  • Напиши <img></img> — посмотри в DevTools, что с этим делает браузер.

13. Что запомнить из урока

  • <img> — одиночный тег, без закрывающей части.
  • Обязательные атрибуты: src (путь) и alt (описание).
  • alt обязателен для доступности. Для декоративных картинок — alt="".
  • width и height указывай парой — предотвращает прыжки контента.
  • Для адаптивности: style="max-width: 100%; height: auto;".
  • loading="lazy" — для картинок ниже первого экрана.
  • Форматы: JPEG для фото, PNG для иконок, SVG для векторных, WebP для современного веба.
  • srcset и sizes — для адаптивных версий одной картинки.
  • Картинка-ссылка: оборачивай в <a>, в alt пиши куда ведёт.
  • Не используй <img> для декоративных фонов — это к CSS.
