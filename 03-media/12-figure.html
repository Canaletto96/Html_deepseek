Урок 12. <figure> и <figcaption>

1. Проблема, которую решает <figure>

Представь, что тебе нужно вставить картинку с подписью. Как это сделать? Новичок напишет так: 

<img src="cat.jpg" alt="Кот">
<p>Рис. 1. Рыжий кот спит на подоконнике</p>

Визуально — работает. Но с точки зрения смысла (семантики) — плохо. Браузер, поисковик и screen reader не понимают, что подпись относится к картинке. Они видят просто «картинка» и «параграф» отдельно.

Для таких случаев в HTML5 придумали теги <figure> и <figcaption>.

2. Что это такое

Тег Что делает Тип
<figure> Контейнер для иллюстрации и её подписи Парный, блочный
<figcaption> Подпись к содержимому figure Парный, блочный 
<figure>
    <img src="cat.jpg" alt="Рыжий кот">
    <figcaption>Рис. 1. Рыжий кот спит на подоконнике</figcaption>
</figure>
Результат:

Теперь браузер, поисковик и screen reader знают: картинка и подпись — единое целое.

3. Правила использования

Правило 1: figcaption — внутри figure

<figcaption> обязательно должен находиться внутри <figure>. Не снаружи. 

<!-- ПРАВИЛЬНО -->
<figure>
    <img src="cat.jpg" alt="Кот">
    <figcaption>Рыжий кот</figcaption>
</figure>

<!-- НЕПРАВИЛЬНО: подпись вне figure -->
<figure>
    <img src="cat.jpg" alt="Кот">
</figure>
<figcaption>Рыжий кот</figcaption>

Правило 2: figcaption — только один

В одном <figure> может быть только один <figcaption>.

Правило 3: figcaption идёт первым или последним

Внутри <figure> <figcaption> должен быть либо первым, либо последним элементом.

<!-- Подпись сверху -->
<figure>
    <figcaption>Рыжий кот</figcaption>
    <img src="cat.jpg" alt="Кот">
</figure>

<!-- Подпись снизу (чаще всего) -->
<figure>
    <img src="cat.jpg" alt="Кот">
    <figcaption>Рыжий кот</figcaption>
</figure>

Правило 4: figure можно использовать без figcaption

Если подпись не нужна — <figcaption> можно не добавлять. Но тогда <figure> имеет смысл только для смысловой группировки.

4. Что можно класть в <figure>

<figure> — не только для картинок. Внутри может быть любой «самодостаточный» контент, который можно переместить в другое место без потери смысла:

Что Пример
Изображение Фото, схема, график
Блок кода Пример программы
Цитата Высказывание с источником
Видео / аудио Ролик, подкаст
Диаграмма SVG-график
Таблица Данные с подписью

6. Как браузер стилизует по умолчанию

  • <figure> — margin: 1em 40px (отступы сверху/снизу и по 40px слева/справа).
  • <figcaption> — display: block, без особых стилей.

Часто эти значения переопределяют в CSS. Например:

figure {
    margin: 24px 0;
    text-align: center;
}

figcaption {
    font-size: 0.9em;
    color: #666;
    font-style: italic;
    margin-top: 8px;
}

7. figure в контексте доступности (a11y)

Screen reader'ы читают <figure> особым образом. В некоторых программах пользователь слышит: «фигура», затем её содержимое, затем подпись.

Важно: alt картинки и figcaption — разные вещи:

  • alt — что изображено (для незрячих, если картинка не загрузилась).
  • figcaption — подпись, которая видна всем (даже когда картинка загружена).
Пример: картинка кота в статье о породах:
  • alt="Британский короткошёрстный кот" — что на картинке
  • figcaption="Рис. 3. Британская порода, 2 года" — подпись к рисунку
Не дублируй одно и то же в обоих местах.

8. figure vs div — в чём разница

<div> <figure>
Смысл Нет (просто контейнер) Самодостаточный блок: иллюстрация + подпись
Подпись Нужна через <p>, смысла нет <figcaption> — семантически связана
Screen reader Игнорируется Особый режим: «фигура», содержимое, подпись
Когда использовать Для любых блоков вёрстки Только для иллюстраций с подписью
Не используй figure для всего подряд. Это семантический тег для конкретного случая: картинка (или другой контент) + подпись. Для общей вёрстки — <div> или семантические теги (<section>, <article>).

9. Частые ошибки

Ошибка Почему плохо
<figcaption> вне <figure> Невалидно, теряется смысл
Несколько <figcaption> в одном <figure> Разрешён только один
<figcaption> в середине контента Должен быть первым или последним
figure без подписи и без смысловой группировки Тогда лучше <div>
Дублировать alt и figcaption Лишний шум для screen reader'ов
Использовать figure для вёрстки страницы Это не «универсальный контейнер», а тег для иллюстраций

11. Практическое задание

Задание 1. «Три фигуры»

Создай файл 12-practice.html. Размести на странице три <figure>:

  • Первая — картинка + подпись «Рис. 1. ...»
  • Вторая — блок кода + подпись «Пример 1. ...»
  • Третья — цитата + источник

Задание 2. «Картинка и подпись отдельно»

  • Сделай картинку с подписью без <figure> — просто <img> + <p>.
  • Сделай то же с <figure> + <figcaption>.
  • Открой DevTools → Elements — увидишь разницу в структуре DOM.

Задание 3. «Стилизация figure»

  • Добавь CSS: figure { border: 1px solid #ddd; padding: 12px; }
  • Сделай figcaption курсивом и серым цветом.
  • Попробуй выровнять подпись по центру.

Задание 4. «Подпись сверху»

  • Сделай <figure>, где <figcaption> идёт перед картинкой.
  • Убедись, что это валидно и работает.

Задание 5. «Сломай и почини»

  • Помести <figcaption> вне <figure> — проверь валидатором (validator.w3.org).
  • Добавь два <figcaption> в одну <figure> — увидишь ошибку валидации.
  • Помести <figcaption> между двумя картинками внутри <figure> — тоже ошибка.

12. Что запомнить из урока

  • <figure> — контейнер для самодостаточного контента: картинка, код, цитата, видео + подпись.
  • <figcaption> — подпись, обязана быть внутри <figure>.
  • Один <figure> — один <figcaption> максимум.
  • Подпись идёт первой или последней, не в середине.
  • figure можно использовать без figcaption, но тогда — только для смысловой группировки.
  • alt ≠ figcaption: alt — что изображено, figcaption — подпись под рисунком.
  • figure — семантический тег, не «универсальный div».
  • Используй figure, когда контент можно «вырезать» и переместить без потери смысла.
