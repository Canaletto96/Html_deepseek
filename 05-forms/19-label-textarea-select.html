Урок 19. Label, textarea, select, button

1. Обзор элементов формы

Тег Для чего
<label> Подпись к полю
<textarea> Многострочное текстовое поле
<select> + <option> Выпадающий список
<optgroup> Группировка в select
<button> Кнопка
<datalist> Подсказки для input
<output> Вывод результата (вычислений)
<fieldset> + <legend> Группировка полей

2. Тег <label> — подпись

Уже знаком, но разберём подробно. <label> делает две вещи:

  • Связывает текст с полем (клик по label фокусирует поле).
  • Улучшает доступность — screen reader читает подпись вместе с полем.

Способ 1: через for + id

<label for="username">Имя пользователя:</label>
<input type="text" id="username" name="username">

Важно: значение for должно совпадать с id поля.

Способ 2: обёртка

<label>
    Имя пользователя:
    <input type="text" name="username">
</label>

Здесь id не нужен — связь создаётся автоматически.

Результат (клик по тексту фокусирует поле):
Особенно важно для checkbox и radio: там поле само маленькое, попасть по нему сложно. С label клик по тексту тоже переключает.

3. Тег <textarea> — многострочное поле

Для комментариев, отзывов, длинных описаний. В отличие от input, это парный тег: текст пишется между тегами. 

<label for="comment">Комментарий:</label>
<textarea id="comment" name="comment" rows="5" cols="40"></textarea>
Результат:

Атрибуты <textarea>

Атрибут Значения Описание
name Текст Имя поля
rows Число Высота в строках текста
cols Число Ширина в символах
placeholder Текст Подсказка
maxlength Число Максимум символов
required булев Обязательное поле
readonly булев Только для чтения
disabled булев Отключено
wrap soft, hard Как переносить строки при отправке
Особенность: textarea сохраняет переносы строк и пробелы внутри. Но первый перенос после открывающего тега игнорируется (как в <pre>).

Начальный текст

<textarea name="comment">Здесь текст по умолчанию.</textarea>
Не используй value у textarea! Это атрибут для <input>. У <textarea> текст пишется между тегами.

4. Тег <select> — выпадающий список

Когда вариантов много и нужно сэкономить место. Состоит из <select> (обёртка) и <option> (пункты). 

<label for="city">Город:</label>
<select id="city" name="city">
    <option value="">-- Выберите город --</option>
    <option value="msk">Москва</option>
    <option value="spb">Санкт-Петербург</option>
    <option value="kzn">Казань</option>
    <option value="nsk">Новосибирск</option>
</select>
Результат:

Атрибуты <select>

Атрибут Значения Описание
name Текст Имя поля
multiple булев Разрешить выбор нескольких вариантов
size Число Сколько вариантов показывать сразу
required булев Обязательный выбор
disabled булев Отключить
autofocus булев Автофокус

Атрибуты <option>

Атрибут Описание
value Значение, которое уйдёт на сервер (если не указано — берётся текст)
selected Выбран по умолчанию
disabled Нельзя выбрать
label Более короткий текст в выпадающем списке 
<select name="city">
    <option value="">-- Выберите --</option>
    <option value="msk" selected>Москва</option>
    <option value="spb">Санкт-Петербург</option>
    <option value="kzn" disabled>Казань (недоступно)</option>
</select>

Множественный выбор (multiple)

<select name="skills" multiple size="4">
    <option value="html">HTML</option>
    <option value="css">CSS</option>
    <option value="js">JavaScript</option>
    <option value="py">Python</option>
</select>
Результат (Ctrl/Cmd + клик для выбора нескольких):
Совет: multiple на мобильных работает плохо. Пользователю непонятно, что можно выбрать несколько. Для множественного выбора чаще используют чекбоксы.

5. Тег <optgroup> — группировка

Разбивает список на логические группы с заголовками.

<select name="car">
    <optgroup label="Немецкие">
        <option value="bmw">BMW</option>
        <option value="audi">Audi</option>
        <option value="mercedes">Mercedes</option>
    </optgroup>
    <optgroup label="Японские">
        <option value="toyota">Toyota</option>
        <option value="honda">Honda</option>
        <option value="nissan">Nissan</option>
    </optgroup>
</select>

6. Тег <button> — кнопка

<button> — современная замена <input type="submit">. Парный, внутри можно разместить не только текст, но и HTML (иконки, картинки). 

<button type="submit">Отправить</button>
<button type="reset">Очистить</button>
<button type="button">Просто кнопка</button>
Результат:

Атрибут type у button

Значение Что делает
submit (по умолчанию) Отправляет форму
reset Сбрасывает форму к начальным значениям
button Ничего не делает — для JavaScript
Всегда указывай type явно! По умолчанию — submit. Если добавишь кнопку «Показать пароль» без type="button" — форма отправится при клике. Это классическая ловушка.

button vs input type="submit"

<button> <input type="submit">
Содержимое Любой HTML Только текст (в value)
Иконки Да (через <img> или SVG) Нет
Стилизация Проще Ограничена
Значение по умолчанию submit submit

Современный подход: используй <button>.

Кнопка с иконкой

<button type="submit">
    <span aria-hidden="true">✓</span>
    Сохранить
</button>

7. Тег <datalist> — подсказки для input

<datalist> даёт подсказки к текстовому полю. Пользователь может выбрать из списка или ввести своё значение. 

<label for="browser">Браузер:</label>
<input list="browsers" id="browser" name="browser">
<datalist id="browsers">
    <option value="Chrome">
    <option value="Firefox">
    <option value="Safari">
    <option value="Edge">
    <option value="Opera">
</datalist>
Результат (начни вводить — появятся подсказки):

datalist vs select

<datalist> <select>
Можно ввести своё Да Нет (только из списка)
Вид Обычное поле с подсказками Выпадающий список
Валидация Свободный ввод Только из вариантов

8. Тег <output> — вывод результата

Показывает результат вычислений (обычно через JavaScript). Например, сумма двух чисел из <input type="range">. 

<form oninput="result.value = parseInt(a.value) + parseInt(b.value)">
    <input type="number" id="a" value="0"> +
    <input type="number" id="b" value="0"> =
    <output name="result" for="a b">0</output>
</form>
Результат (введи числа):
+ = 0

9. Тег <fieldset> и <legend>

Группировка связанных полей с рамкой и заголовком. Особенно важно для radio-групп — иначе screen reader не понимает, что это одна группа. 

<fieldset>
    <legend>Способ доставки</legend>

    <label><input type="radio" name="delivery" value="pickup" checked> Самовывоз</label>
    <label><input type="radio" name="delivery" value="courier"> Курьер</label>
    <label><input type="radio" name="delivery" value="post"> Почта</label>
</fieldset>

10. Полная форма: всё вместе

<form action="/order" method="post">

    <fieldset>
        <legend>Контактные данные</legend>

        <label for="name">Имя:</label>
        <input type="text" id="name" name="name" required>

        <label for="email">Email:</label>
        <input type="email" id="email" name="email" required>

        <label for="phone">Телефон:</label>
        <input type="tel" id="phone" name="phone">
    </fieldset>

    <fieldset>
        <legend>Доставка</legend>

        <label for="city">Город:</label>
        <select id="city" name="city" required>
            <option value="">-- Выберите --</option>
            <option value="msk">Москва</option>
            <option value="spb">Санкт-Петербург</option>
        </select>

        <label for="address">Адрес:</label>
        <textarea id="address" name="address" rows="3"></textarea>
    </fieldset>

    <fieldset>
        <legend>Способ оплаты</legend>

        <label><input type="radio" name="payment" value="card" checked> Карта</label>
        <label><input type="radio" name="payment" value="cash"> Наличные</label>
    </fieldset>

    <label for="comment">Комментарий к заказу:</label>
    <textarea id="comment" name="comment" rows="4"></textarea>

    <button type="submit">Оформить заказ</button>
    <button type="reset">Очистить</button>
</form>

11. Частые ошибки

Ошибка Почему плохо
Забыть name у select / textarea Не отправится на сервер
Использовать value у textarea Не работает — текст пишется между тегами
Не указывать type у button Станет submit и отправит форму
Опции select без value Уйдёт текст опции, а не код (иногда это не то)
Забыть placeholder-опцию в select Первый вариант будет выбран по умолчанию
Использовать select для множественного выбора Лучше checkbox-группа для UX
Не связывать label с полем Плохо для a11y и кликов
