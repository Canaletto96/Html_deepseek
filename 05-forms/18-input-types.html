Урок 18. Все типы <input>

1. Что такое <input>

<input> — одиночный тег для ввода данных. У него нет содержимого — всё настраивается через атрибуты.

Главный атрибут — type. Он определяет вид поля: текстовое, пароль, чекбокс, дата, файл и т.д. Всего около 20 типов. 

<input type="text" name="username">
<input type="email" name="email">
<input type="checkbox" name="agree">

2. Текстовые поля

type="text" — обычный текст

<label for="name">Имя:</label>
<input type="text" id="name" name="name" placeholder="Иван">
Результат:

type="password" — скрытый текст

Символы отображаются точками. Значение всё равно отправляется открыто — для безопасности нужен HTTPS.

<label for="pwd">Пароль:</label>
<input type="password" id="pwd" name="password">
Результат:

type="email" — email

Браузер проверяет формат (должна быть @ и домен). На мобильных открывает клавиатуру с @.

<input type="email" name="email" placeholder="user@example.com">
Результат (попробуй ввести без @):

type="tel" — телефон

На мобильных открывает цифровую клавиатуру. Формат не проверяется — он слишком разный в разных странах.

<input type="tel" name="phone" placeholder="+7 900 123-45-67">

type="url" — адрес сайта

<input type="url" name="website" placeholder="https://example.com">

type="search" — поиск

Как text, но с крестиком для очистки и возможной историей.

<input type="search" name="q" placeholder="Поиск...">

5. Чекбоксы и радиокнопки

type="checkbox" — флажок

Можно выбрать несколько. Подходит для «согласен с условиями», «выберите интересы».

<label><input type="checkbox" name="subscribe" value="yes"> Подписаться на рассылку</label>
<label><input type="checkbox" name="news" value="yes" checked> Получать новости</label>
Результат:

type="radio" — радиокнопка

Можно выбрать только один вариант из группы. Все радио одной группы должны иметь одинаковый name.

<label><input type="radio" name="gender" value="m"> Мужской</label>
<label><input type="radio" name="gender" value="f"> Женский</label>
<label><input type="radio" name="gender" value="other"> Другой</label>
Результат (можно выбрать только один):
Ключевое отличие: checkbox — «много из многих», radio — «один из многих». И у radio одинаковый name, иначе они не связаны в группу.

6. Специальные поля

type="file" — загрузка файлов

<input type="file" name="avatar" accept="image/*">
<input type="file" name="docs" accept=".pdf,.docx" multiple>
Результат:
Для загрузки файлов на форме обязательно method="post" и enctype="multipart/form-data". Иначе файл не отправится.

type="color" — выбор цвета

<input type="color" name="favorite-color" value="#b5651d">
Результат:

type="hidden" — скрытое поле

Пользователь не видит, но значение отправляется на сервер. Для технических данных: id пользователя, токен.

<input type="hidden" name="user_id" value="12345">
Не храни в hidden ничего секретного! Пользователь может открыть DevTools и увидеть или изменить значение. Только для технических данных.

type="submit" — кнопка отправки

<input type="submit" value="Отправить">
Результат (это и есть кнопка, а не просто текст):

type="reset" — сброс формы

<input type="reset" value="Очистить">

type="button" — просто кнопка

Не отправляет форму. Для JavaScript-действий.

<input type="button" value="Нажми меня" onclick="alert('Привет!')">

type="image" — кнопка-картинка

<input type="image" src="button.png" alt="Отправить" width="100">

8. Разница: disabled vs readonly

disabled readonly
Можно изменить Нет Нет
Отправляется на сервер Нет Да
Клик по полю Не фокусируется Фокусируется, можно копировать
Стилизация Серый, недоступный Обычный вид 
<!-- Отправляется, но нельзя изменить -->
<input type="text" name="username" value="ivan" readonly>

<!-- НЕ отправляется, полностью отключено -->
<input type="text" name="hidden-field" value="secret" disabled>

9. Связка label + input

Два способа связать <label> с полем: 

<!-- Способ 1: id + for -->
<label for="email-field">Email:</label>
<input type="email" id="email-field" name="email">

<!-- Способ 2: обёртка -->
<label>
    Email:
    <input type="email" name="email">
</label>

Зачем это нужно: клик по label фокусирует поле. Удобно для чекбоксов (легче попасть). И для screen reader'ов — читается связка «Email: поле ввода».

11. Частые ошибки

Ошибка Почему плохо
Забыть name Поле не отправится
Использовать type="text" для email/телефона/даты Теряется валидация и удобная клавиатура на мобильных
Разные name у radio одной группы Они не будут связаны, можно выбрать несколько
type="file" без enctype Файл не отправится
disabled вместо readonly Поле не отправится на сервер
Отсутствие label Плохо для a11y и кликов
Хранить пароли в type="hidden" Пользователь увидит через DevTools
Использовать placeholder вместо label Подсказка исчезает при вводе, плохо для a11y

12. Полный пример формы

<form action="/register" method="post" enctype="multipart/form-data">
    <fieldset>
        <legend>Регистрация</legend>

        <label for="f-name">Имя:</label>
        <input type="text" id="f-name" name="name" required placeholder="Иван">

        <label for="f-email">Email:</label>
        <input type="email" id="f-email" name="email" required>

        <label for="f-pwd">Пароль:</label>
        <input type="password" id="f-pwd" name="password" minlength="8" required>

        <label for="f-birth">Дата рождения:</label>
        <input type="date" id="f-birth" name="birthday">

        <label for="f-avatar">Аватар:</label>
        <input type="file" id="f-avatar" name="avatar" accept="image/*">

        <label for="f-color">Любимый цвет:</label>
        <input type="color" id="f-color" name="color" value="#b5651d">

        <fieldset>
            <legend>Пол:</legend>
            <label><input type="radio" name="gender" value="m"> Мужской</label>
            <label><input type="radio" name="gender" value="f"> Женский</label>
        </fieldset>

        <label>
            <input type="checkbox" name="agree" required>
            Я согласен с условиями
        </label>

        <button type="submit">Зарегистрироваться</button>
    </fieldset>
</form>
