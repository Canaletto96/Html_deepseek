Справочник: Элементы внутри <head>

Полный список тегов, разрешённых в <head>, с атрибутами и значениями.

Навигация по тегам:
  • <title> — заголовок документа
  • <meta> — метаданные (charset, viewport, description и др.)
  • <link> — подключение внешних ресурсов (CSS, favicon)
  • <base> — базовый URL для всех ссылок
  • <style> — встроенные CSS-стили
  • <script> — подключение JavaScript
  • <noscript> — контент при отключённом JS
  • <template> — шаблон для клонирования

<title>

Назначение: Задаёт заголовок документа, который отображается на вкладке браузера, в закладках и в результатах поиска.

Содержимое: Только текст. Нельзя вкладывать другие теги.

Ограничение: Ровно один <title> на страницу.

Атрибуты

Атрибут Значение Описание
Глобальные атрибуты (id, class, lang, dir, data-* и др.) — работают, но на практике почти не используются. 
<title>Купить кота — Магазин Мурлыка</title>

<meta>

Назначение: Предоставляет метаданные о документе — поисковым системам, браузерам и другим клиентам.

Тип тега: Одиночный (не имеет закрывающего тега).

Ограничение: В стандарте есть только определённые имена для name и зарегистрированные расширения. Валидаторы проверяют это.

Важно: В зависимости от того, какой атрибут используется (name, http-equiv, charset, property), значения будут разными. Ниже — все основные варианты.

Вариант 1: name + content

Пары «имя-значение» для метаданных.

name content (значения) Описание
description Строка, описывающая страницу Краткое описание для поисковиков. Один на страницу.
author Имя автора Автор документа.
keywords Слова через запятую Ключевые слова (сейчас почти не используется).
application-name Название приложения Имя веб-приложения, которое представляет страница.
generator Название ПО Программа, создавшая документ (CMS, редактор).
viewport width=device-width, initial-scale=1.0 Управление масштабированием на мобильных (зарегистрированное имя).
robots index, noindex, follow, nofollow, nosnippet, noarchive и др. Инструкции для поисковых роботов.
googlebot Те же значения, что и robots Инструкции только для Googlebot.
google-site-verification Строка-токен Подтверждение прав в Google Search Console.
theme-color Цвет (HEX, RGB) Цвет адресной строки на мобильных (зарегистрированное имя). 
<meta name="description" content="Уроки HTML для начинающих">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="robots" content="noindex, nofollow">

Вариант 2: charset

Указывает кодировку документа. Заменяет старый http-equiv="Content-Type".

Атрибут Значения Описание
charset UTF-8 (рекомендуется), windows-1251, ISO-8859-1 и др. Кодировка символов. UTF-8 поддерживает все языки. 
<meta charset="UTF-8">

Вариант 3: http-equiv + content

Эмуляция HTTP-заголовков. Используется для старых механизмов и специальных инструкций.

http-equiv content Описание
refresh 5 или 5; url=https://example.com Автоматическое обновление / редирект через N секунд.
Content-Type text/html; charset=UTF-8 Устаревший способ указать тип и кодировку.
X-UA-Compatible IE=edge Для старых версий Internet Explorer (устарело). 
<meta http-equiv="refresh" content="30">
<!-- страница обновится через 30 секунд -->

Вариант 4: property + content (Open Graph)

Не входит в стандарт HTML, но широко используется для соцсетей (Facebook, Twitter, Telegram).

property content Описание
og:title Заголовок Заголовок при шаринге в соцсетях.
og:description Описание Описание при шаринге.
og:image URL картинки Превью при шаринге.
og:url URL страницы Канонический URL.
og:type website, article, video.movie и др. Тип контента. 
<meta property="og:title" content="Уроки HTML">
<meta property="og:image" content="https://example.com/preview.jpg">

<link>

Назначение: Подключает внешние ресурсы (CSS, favicon, шрифты) и задаёт связи между документами.

Тип тега: Одиночный.

Атрибуты

Атрибут Обязательный? Значения Описание
rel Да stylesheet, icon, canonical, alternate, preload, author, license и др. Тип связи с ресурсом.
href Зависит от rel URL Адрес ресурса.
type Нет MIME-тип: text/css, image/png, font/woff2 Подсказка браузеру о типе ресурса.
media Нет Медиа-запросы: all, screen, print, (max-width: 600px) Для каких устройств/условий применять ресурс. По умолчанию all.
hreflang Нет Код языка: ru, en, de Язык ресурса (для alternate).
sizes Нет 16x16, 32x32, any Размеры иконки (только для rel="icon").
title Нет Текст Для альтернативных стилей — имя набора.
as Нет style, script, font, image Тип ресурса для preload. 
<!-- Подключение CSS -->
<link rel="stylesheet" href="style.css">

<!-- Favicon -->
<link rel="icon" href="favicon.ico" sizes="32x32">

<!-- Канонический URL -->
<link rel="canonical" href="https://example.com/page">

<!-- Предзагрузка шрифта -->
<link rel="preload" href="font.woff2" as="font" type="font/woff2" crossorigin>

<base>

Назначение: Задаёт базовый URL и/или цель по умолчанию для всех относительных ссылок в документе.

Тип тега: Одиночный.

Ограничение: Ровно один на документ. Должен идти до любых элементов с URL-атрибутами.

Атрибуты

Атрибут Обязательный? Значения Описание
href Хотя бы один из двух URL Базовый URL для всех относительных ссылок.
target Хотя бы один из двух _blank, _self, _parent, _top, имя фрейма Куда открывать ссылки по умолчанию. 
<base href="https://example.com/news/" target="_blank">
Осторожно: Если указать href, все относительные ссылки и якоря (#id) будут разрешаться относительно базового URL. Это может сломать навигацию, если не учесть.

<style>

Назначение: Встраивает CSS-стили прямо в HTML-документ.

Тип тега: Парный. Содержимое — CSS-код (текст).

Атрибуты

Атрибут Значения Описание
media all, screen, print, медиа-запросы К каким медиа применять стили. По умолчанию all.
type text/css (по умолчанию) MIME-тип языка стилей.
title Текст Определяет альтернативный набор стилей.
scoped (устарел) булев Ограничивал стили родительским элементом. Удалён из стандарта. 
<style>
    body { font-family: sans-serif; }
    h1 { color: #333; }
</style>

<style media="print">
    /* стили только для печати */
</style>

<script>

Назначение: Подключает JavaScript или другие скрипты к документу.

Тип тега: Парный (если код внутри) или с src (тогда можно закрыть сразу).

Атрибуты

Атрибут Значения Описание
src URL Адрес внешнего файла со скриптом.
type text/javascript, module, MIME-тип Язык скрипта. По умолчанию JavaScript.
async булев Загружать и выполнять асинхронно (как только загрузится).
defer булев Выполнить после парсинга HTML.
charset UTF-8 и др. Кодировка внешнего файла (только с src).
crossorigin anonymous, use-credentials Настройки CORS для внешних скриптов.
integrity Хеш (например, sha384-...) Проверка целостности внешнего файла (SRI).
nomodule булев Не выполнять в браузерах с поддержкой ES-модулей. 
<!-- Внешний скрипт -->
<script src="app.js" defer></script>

<!-- Встроенный код -->
<script>
    console.log("Привет!");
</script>

<!-- ES-модуль -->
<script type="module" src="main.js"></script>

<noscript>

Назначение: Показывает содержимое, если JavaScript отключён в браузере.

Тип тега: Парный.

Атрибуты

Только глобальные атрибуты.

<noscript>
    <p>Для работы сайта включите JavaScript.</p>
</noscript>

<template>

Назначение: Хранит фрагмент HTML, который не отображается, но может быть клонирован через JavaScript.

Тип тега: Парный.

Атрибуты

Только глобальные атрибуты.

<template id="card-template">
    <div class="card">
        <h3></h3>
        <p></p>
    </div>
</template>

Итоговая таблица: что где использовать

Задача Тег Пример
Заголовок вкладки <title> <title>Мой сайт</title>
Кодировка <meta charset> <meta charset="UTF-8">
Мобильная адаптация <meta name="viewport"> <meta name="viewport" content="width=device-width, initial-scale=1.0">
Описание для поиска <meta name="description"> <meta name="description" content="...">
Индексация <meta name="robots"> <meta name="robots" content="noindex">
Подключить CSS <link rel="stylesheet"> <link rel="stylesheet" href="style.css">
Favicon <link rel="icon"> <link rel="icon" href="favicon.ico">
Базовый URL <base> <base href="https://example.com/">
CSS в HTML <style> <style>body { color: red; }</style>

Для отключённого JS <noscript> <noscript>Включите JS</noscript>
Шаблон для клонирования <template> <template>...</template>

Что НЕЛЬЗЯ класть в <head>

Запрещённые теги: <img>, <iframe>, <div>, <p>, <h1>, <a> и любой другой контентный тег.

Поисковые роботы (включая Google) прекращают чтение <head>, как только встречают запрещённый элемент. Всё, что идёт после него, будет проигнорировано.

<head>
    <meta charset="UTF-8">
    <title>Правильно</title>
    <img src="logo.png">
    <!-- Всё, что идёт после <img>, Google может проигнорировать -->
</head>
