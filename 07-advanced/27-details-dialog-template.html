Урок 27. Details, dialog, template, slot

1. Что за теги

Тег Для чего
<details> + <summary> Раскрывающийся блок (аккордеон) без JavaScript
<dialog> Модальное окно (popup) без JavaScript-библиотек
<template> Шаблон HTML, который не отображается, но может клонироваться через JS
<slot> Место для вставки контента (для Web Components)

2. <details> и <summary> — аккордеон

Раскрывающийся блок без единой строчки JavaScript. Пользователь кликает на заголовок — контент появляется. 

<details>
    <summary>Что такое HTML?</summary>
    <p>HTML — это язык разметки для создания страниц.</p>
</details>
Результат (кликни по заголовку):
Что такое HTML?

HTML — это язык разметки для создания страниц. Он описывает структуру, а не внешний вид.

Что такое CSS?

CSS — это язык стилей. Он отвечает за оформление: цвета, шрифты, отступы.

Что такое JavaScript?

JavaScript — это язык программирования. Он добавляет интерактивность: анимации, формы, игры.

Структура

  • <details> — контейнер раскрывающегося блока.
  • <summary> — заголовок (по нему кликают). Первый элемент внутри.
  • Всё остальное содержимое внутри <details> — скрытый контент.

Атрибуты

Атрибут Значения Что делает
open булев Раскрыт по умолчанию 
<!-- Открыт по умолчанию -->
<details open>
    <summary>Важная информация</summary>
    <p>Этот текст виден сразу.</p>
</details>
Открыт по умолчанию:
Открыт сразу

Этот контент виден без клика.

Где использовать

  • FAQ — вопросы-ответы.
  • Спойлеры — «показать решение».
  • Оглавление — скрытые разделы.
  • Длинные описания — «читать далее».
  • Настройки — «расширенные опции».
Важно: <details> работает без JavaScript. Это встроенная функция браузера. Никакие библиотеки не нужны.

3. <dialog> — модальное окно

Встроенный в браузер popup. Раньше для модальных окон нужны были библиотеки (Bootstrap, jQuery UI). Теперь — нативно. 

<dialog id="myDialog">
    <h2>Заголовок окна</h2>
    <p>Содержимое модального окна.</p>
    <button id="closeBtn">Закрыть</button>
</dialog>

<button id="openBtn">Открыть окно</button>

<script>
    const dialogEl = document.getElementById('myDialog');
    document.getElementById('openBtn').onclick = () => dialogEl.showModal();
    document.getElementById('closeBtn').onclick = () => dialogEl.close();
</script>
Результат (нажми кнопку):

Привет!

Это нативное модальное окно на теге <dialog>.

Оно перекрывает страницу полупрозрачным фоном и закрывается по Escape.

Методы dialog (JavaScript)

Метод Что делает
showModal() Открывает как модальное (с backdrop, блокирует страницу)
show() Открывает как немодальное (без backdrop)
close() Закрывает окно

Особенности <dialog>

  • Backdrop — полупрозрачный фон создаётся автоматически.
  • Escape — закрывает окно по умолчанию.
  • Фокус — автоматически переходит в окно.
  • Форма — внутри можно использовать <form method="dialog"> — кнопка закроет окно.

Стилизация backdrop

dialog::backdrop {
    background: rgba(0, 0, 0, 0.5);
    backdrop-filter: blur(4px);
}

4. <template> — шаблон для клонирования

<template> хранит HTML-код, который не отображается на странице, но может быть использован через JavaScript для создания копий. 

<template id="card-template">
    <div class="card">
        <h3>Название</h3>
        <p>Описание</p>
    </div>
</template>

<div id="container"></div>

<script>
    const template = document.getElementById('card-template');
    const clone = template.content.cloneNode(true);
    document.getElementById('container').appendChild(clone);
</script>
Результат (шаблон не виден, но при клике клонируется):

Зачем нужен template

  • Повторяющиеся блоки — карточки товаров, посты, комментарии.
  • Динамический контент — список загружается с сервера, HTML — из шаблона.
  • Web Components — основа для создания своих компонентов.

Ключевые особенности

  • Содержимое не отображается и не загружается (картинки внутри не тянутся).
  • Не участвует в DOM — нужно клонировать через JS.
  • Доступ через template.content.
  • Можно клонировать бесконечно через cloneNode(true).

5. <slot> — место для контента

<slot> используется в Web Components — технологии для создания своих HTML-компонентов.

Это «дырка» в шаблоне компонента, куда вставляется содержимое:

<!-- Определяем компонент -->
<template id="my-card">
    <div class="card">
        <h3><slot name="title">Заголовок по умолчанию</slot></h3>
        <div><slot>Текст по умолчанию</slot></div>
    </div>
</template>
Сейчас можно пропустить. Знай, что <slot> существует и используется в компонентном подходе. Подробности — в курсе по современному JavaScript или Web Components.

8. Что запомнить из урока

  • <details> + <summary> — раскрывающийся блок без JS.
  • <summary> — первый элемент внутри <details>.
  • <details open> — раскрыт по умолчанию.
  • Псевдокласс [open] — стилизация открытого состояния.
  • <dialog> — встроенное модальное окно.
  • Открывается через JS: showModal(). Закрывается: close() или Escape.
  • Стилизация фона — ::backdrop.
  • <template> — HTML-шаблон, невидимый на странице. Клонируется через JS.
  • <slot> — для Web Components. Пока можно пропустить.
  • Большинство из этого — работает нативно, без сторонних библиотек.
