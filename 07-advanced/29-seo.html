Урок 29. SEO-основы в HTML

1. Что такое SEO

SEO (Search Engine Optimization) — оптимизация сайта для поисковых систем. Цель — чтобы сайт показывался выше в результатах поиска Google, Яндекс, Bing.

SEO делится на три части:

Тип Что входит
Техническое SEO Скорость, мобильность, sitemap, robots.txt, HTTPS
Контентное SEO Тексты, заголовки, ключевые слова, структура
Внешнее SEO Ссылки с других сайтов (backlinks)

В этом уроке — то, что относится к HTML: метатеги, семантика, структура. Это не «магия», которая поднимет сайт в топ сама по себе, но база, без которой поисковики не поймут страницу.

Важно: SEO — это долгосрочная игра. Один урок не сделает сайт популярным. Но правильная разметка — обязательное условие. Самое важное — качественный контент. Без него никакие метатеги не помогут.

2. Как Google «видит» страницу

  1. Сканирует (crawling) — робот Googlebot обходит сайты, переходит по ссылкам.
  2. Индексирует (indexing) — сохраняет содержимое в базу.
  3. Ранжирует (ranking) — сортирует по релевантности запросу.
  4. Показывает (serving) — выдаёт пользователю результаты.

HTML влияет на все этапы: робот читает HTML, из него извлекаются заголовки, описание, структура. Если HTML плохой — робот не поймёт, о чём страница.

3. Как выглядит результат поиска

В выдаче Google для каждой страницы показывается:

example.com › blog
Как варить кофе: пошаговый рецепт для начинающих
Узнайте, как правильно варить кофе в турке, кофемашине и френч-прессе. Секреты вкусного напитка и типичные ошибки.

Три элемента — и каждый задаётся своим тегом:

Часть выдачи Откуда берётся
URL (зелёный) Структура сайта + <link rel="canonical">
Заголовок (синий) <title> + <h1>
Описание (серый) <meta name="description">

4. title — самый важный тег

<title> — это самый важный тег для SEO. Google использует его как заголовок в выдаче. Показывается на вкладке браузера и в закладках. 

<title>Как варить кофе: пошаговый рецепт для начинающих</title>

Правила хорошего title

  • Длина: до 60 символов (длиннее — обрежется в выдаче).
  • Уникальный: на каждой странице свой.
  • Ключевые слова в начале: «Как варить кофе» → «Как варить кофе — Блог Ивана».
  • Описательный: понятно, о чём страница.
  • Без спама: «Купить кофе, купить кофе, купить кофе» — плохо.
  • Бренд в конце: «... — Название сайта».
Плохо Хорошо
Главная Мой блог — о кофе и чае
Купить кофе купить кофе купить кофе Купить кофе в Москве — Питомник «Мурлыка»
Page 1 Как варить кофе в турке: рецепт
Очень длинный title на 200 символов Короткий, до 60 символов
Проверить длину: используй SERP Snippet Optimizer — он покажет, как title обрежется в Google.

5. meta description — описание

<meta name="description"> — краткое описание страницы. Google может использовать его как сниппет в выдаче. 

<meta name="description" content="Пошаговый рецепт вкусного кофе в турке. Секреты правильной пропорции, температуры и помола. Для начинающих.">

Правила

  • Длина: 120–160 символов.
  • Уникальный: на каждой странице свой.
  • Описывает пользу: что человек получит на странице.
  • Без спама: «купить купить купить» — плохо.
  • С призывом: «Узнайте, как...».
Google не гарантирует, что покажет твой description. Если он решит, что сниппет из текста страницы лучше — покажет его. Но хороший description увеличивает шанс, что покажут именно его.

6. h1 — заголовок страницы

<h1> — главный заголовок. Google использует его, чтобы понять тему страницы. 

<h1>Как варить кофе в турке: пошаговый рецепт</h1>

Правила

  • Один <h1> на страницу (урок 5).
  • Совпадает по теме с <title>, но может быть длиннее.
  • Содержит ключевой запрос: если страница про кофе в турке — «кофе в турке» в h1.
  • Виден пользователю: h1 — это видимый заголовок на странице, не только для SEO.

title vs h1

<title> <h1>
Где видно Вкладка, закладки, выдача На самой странице
Длина До 60 символов Любая
Совпадает? Не обязательно, но об одной теме

7. Open Graph — для соцсетей

Когда пользователь кидает ссылку в Telegram, WhatsApp, Facebook — мессенджер показывает карточку с картинкой, заголовком и описанием. Эти данные берутся из Open Graph (OG). 

<meta property="og:title" content="Как варить кофе в турке">
<meta property="og:description" content="Пошаговый рецепт для начинающих">
<meta property="og:image" content="https://example.com/coffee.jpg">
<meta property="og:url" content="https://example.com/blog/coffee">
<meta property="og:type" content="article">
☕ Кофе
Как варить кофе в турке
Пошаговый рецепт для начинающих. Секреты вкусного напитка.
example.com

Основные OG-теги

Свойство Что задаёт
og:title Заголовок карточки
og:description Описание карточки
og:image Картинка-превью (1200×630 px)
og:url Канонический URL
og:type Тип: website, article, video.movie
og:site_name Название сайта
og:locale Язык: ru_RU, en_US

Twitter Cards

Для Twitter (X) — свои теги с префиксом twitter:: 

<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="Как варить кофе">
<meta name="twitter:description" content="Пошаговый рецепт">
<meta name="twitter:image" content="https://example.com/coffee.jpg">
Twitter часто автоматически подхватывает OG-теги. Но для точного контроля добавляют и twitter:*.

8. link rel="canonical" — канонический URL

Проблема: одна и та же страница может быть доступна по нескольким URL:

  • https://example.com/page
  • https://example.com/page/ (со слэшем)
  • https://example.com/page?utm_source=twitter
  • https://example.com/page?ref=facebook

Для Google это разные страницы. Это размывает SEO-вес. Решение — <link rel="canonical">. 

<link rel="canonical" href="https://example.com/page">

Это говорит Google: «главная версия страницы — вот эта. Все остальные — копии, не индексируй их отдельно».

Когда нужен canonical:
  • Страница доступна по нескольким URL.
  • URL с UTM-метками (для аналитики).
  • Пагинация (страницы /page/1, /page/2 — каждая со своим canonical).
  • Параметры фильтрации (товары с фильтрами).

9. Структурированные данные (JSON-LD)

Schema.org — словарь для описания контента: статьи, товара, рецепта, события. Google использует эти данные для «расширенных сниппетов»: рейтинги, цены, даты. 

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "Как варить кофе в турке",
  "author": {
    "@type": "Person",
    "name": "Иван Иванов"
  },
  "datePublished": "2026-01-15"
}
</script>

Это продвинутая тема. Но знать, что она есть — полезно. Если у тебя блог о рецептах или магазин — структурированные данные могут дать красивые сниппеты в выдаче.

Проверить свои данные: Google Rich Results Test.

10. Семантика и SEO

Семантические теги (урок 22) помогают Google понять структуру:

  • <main> — основной контент, не меню/футер.
  • <article> — отдельная статья, может быть в выдаче Google Discover.
  • <nav> — навигация, не индексируется как контент.
  • <aside> — дополнительно, менее важно.
  • <time> — дата публикации (важно для новостей).
<article>
    <header>
        <h1>Как варить кофе</h1>
        <time datetime="2026-01-15">15 января 2026</time>
    </header>
    <p>Текст...</p>
</article>

<time> с атрибутом datetime — для Google это сигнал «свежий контент». Особенно важно для новостных сайтов.

11. robots.txt и sitemap.xml

robots.txt

Файл в корне сайта. Говорит роботам, что можно индексировать: 

User-agent: *
Disallow: /admin/
Disallow: /cart/

Sitemap: https://example.com/sitemap.xml

sitemap.xml

Список всех страниц сайта — чтобы робот их нашёл быстрее: 

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
    <url>
        <loc>https://example.com/</loc>
        <lastmod>2026-01-15</lastmod>
    </url>
    <url>
        <loc>https://example.com/blog/</loc>
        <lastmod>2026-01-10</lastmod>
    </url>
</urlset>
Это файлы в корне сайта, не HTML-теги. Но знать про них важно. Google Search Console подскажет, как их настроить.

12. Что НЕ влияет на SEO (мифы)

  • <meta name="keywords"> — игнорируется Google с 2009 года. Не используй.
  • Количество слов — не важно само по себе. Важно качество.
  • Плотность ключевых слов — «ключевое слово в 5% текста» — плохо. Пиши естественно.
  • Покупка ссылок — Google наказывает за это.
  • Скрытый текст — «белый на белом» — бан.

13. Чек-лист SEO для каждой страницы

Проверь любую свою страницу:

Основное

  • ☐ <title> — до 60 символов, уникальный, с ключевым словом.
  • ☐ <meta name="description"> — 120–160 символов, уникальное.
  • ☐ <h1> — один на странице, содержит тему.
  • ☐ <html lang="ru"> — язык указан.
  • ☐ <meta charset="UTF-8"> — кодировка.
  • ☐ <meta name="viewport"> — мобильная адаптация.

Соцсети

  • ☐ og:title, og:description, og:image.
  • ☐ twitter:card, twitter:title, twitter:image.

Структура

  • ☐ Семантические теги: <header>, <nav>, <main>, <article>, <footer>.
  • ☐ Иерархия заголовков: h1 → h2 → h3.
  • ☐ Ссылки с осмысленным текстом (не «здесь»).
  • ☐ Изображения с alt.
  • ☐ <time datetime> для дат.

Техническое

  • ☐ <link rel="canonical"> — если есть дубли URL.
  • ☐ robots.txt — если есть что закрыть.
  • ☐ sitemap.xml — для поисковиков.
  • ☐ HTTPS (SSL-сертификат).
  • ☐ Быстрая загрузка (Lighthouse).

Не делать

  • ☐ Не использовать <meta name="keywords">.
  • ☐ Не спамить ключами в тексте.
  • ☐ Не скрывать текст.
  • ☐ Не покупать ссылки.

14. Полный шаблон SEO-страницы

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <!-- Основное SEO -->
    <title>Как варить кофе в турке: пошаговый рецепт</title>
    <meta name="description" content="Пошаговый рецепт вкусного кофе в турке. Секреты пропорций, температуры и помола. Для начинающих.">
    <meta name="author" content="Иван Иванов">

    <!-- Open Graph (соцсети) -->
    <meta property="og:title" content="Как варить кофе в турке">
    <meta property="og:description" content="Пошаговый рецепт для начинающих">
    <meta property="og:image" content="https://example.com/coffee.jpg">
    <meta property="og:url" content="https://example.com/blog/coffee">
    <meta property="og:type" content="article">
    <meta property="og:locale" content="ru_RU">

    <!-- Twitter -->
    <meta name="twitter:card" content="summary_large_image">
    <meta name="twitter:title" content="Как варить кофе в турке">
    <meta name="twitter:description" content="Пошаговый рецепт для начинающих">
    <meta name="twitter:image" content="https://example.com/coffee.jpg">

    <!-- Канонический URL -->
    <link rel="canonical" href="https://example.com/blog/coffee">

    <!-- Favicon -->
    <link rel="icon" href="/favicon.ico">
</head>
<body>
    <header>
        <nav>...</nav>
    </header>

    <main>
        <article>
            <header>
                <h1>Как варить кофе в турке: пошаговый рецепт</h1>
                <time datetime="2026-01-15">15 января 2026</time>
            </header>
            <p>Текст статьи...</p>
        </article>
    </main>

    <footer>...</footer>
</body>
</html>

15. Практическое задание

Задание 1. «SEO-страница»

Создай файл 29-practice.html. Сделай страницу о своём хобби:

  • <title> — до 60 символов, с ключевым словом.
  • <meta name="description"> — 120–160 символов.
  • Один <h1> с темой.
  • 2–3 <h2> для разделов.
  • OG-теги: og:title, og:description, og:image, og:type="article".
  • Семантические теги: <header>, <main>, <article>, <footer>.
  • <time datetime> для даты публикации.
  • <link rel="canonical">.

Задание 2. «Проверь title»

  • Открой SERP Snippet Optimizer.
  • Введи свой title и description.
  • Посмотри, как они обрежутся в Google.
  • Если длиннее 60/160 — сократи.

Задание 3. «OG-превью»

  • Открой opengraph.xyz.
  • Введи URL любой известной страницы (например, https://developer.mozilla.org/ru/).
  • Посмотри, как выглядит карточка в соцсетях.
  • Сравни со своими OG-тегами.

Задание 4. «Аудит через Lighthouse»

  • Открой свою страницу в Chrome.
  • F12 → Lighthouse → только SEO.
  • Получи оценку. Прочитай рекомендации.
  • Исправь проблемы, проверь снова.

Задание 5. «Сломай и почини»

  • Добавь <meta name="keywords" content="кофе, рецепт"> — узнай, что Google его игнорирует.
  • Сделай title длиной 150 символов — увидишь, как он обрежется в выдаче.
  • Убери <meta name="description"> — Google возьмёт случайный текст со страницы.
  • Добавь три <h1> — проверь через валидатор (формально не ошибка, но плохо для SEO).

16. Что запомнить из урока

  • SEO — оптимизация для поисковых систем. Делится на техническое, контентное и внешнее.
  • <title> — самый важный тег. До 60 символов, уникальный, с ключевым словом.
  • <meta name="description"> — 120–160 символов. Google может использовать его в сниппете.
  • <h1> — один на страницу, содержит тему.
  • Open Graph (og:*) — для красивых карточек в соцсетях.
  • <link rel="canonical"> — для дублей URL.
  • Семантика — <main>, <article>, <time> помогают Google понять структуру.
  • robots.txt и sitemap.xml — технические файлы в корне сайта.
  • Структурированные данные (JSON-LD) — для расширенных сниппетов.
  • Не работает: <meta name="keywords">, спам ключами, скрытый текст, покупка ссылок.
  • Главное — контент. Метатеги не спасут плохую страницу.
