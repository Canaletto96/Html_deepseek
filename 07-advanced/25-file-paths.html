Урок 25. Пути к файлам

1. Зачем нужны пути

Когда ты пишешь <img src="cat.jpg"> или <a href="about.html">, браузер должен найти файл. Путь — это «адрес», по которому браузер ищет файл.

Есть два основных типа путей:

Тип Пример Когда использовать
Относительный cat.jpg, ../images/cat.jpg Свои файлы на сайте
Абсолютный https://example.com/cat.jpg Чужие файлы (внешние)

2. Структура папок — пример

Представь такой проект:

my-site/ ├── index.html ← мы здесь ├── about.html ├── pages/ │ ├── blog.html │ └── article.html └── images/ ├── logo.png └── cat.jpg

Текущий файл — index.html в корне. От него и строятся относительные пути.

3. Относительные пути

Относительный путь — адрес файла относительно текущего документа. Не содержит домена и протокола.

Файл в той же папке

Просто имя файла:

<!-- Из index.html ссылаемся на about.html -->
<a href="about.html">О нас</a>

Файл во вложенной папке

Указываем папку и файл через /:

<!-- Из index.html в pages/blog.html -->
<a href="pages/blog.html">Блог</a>

<!-- Из index.html в images/logo.png -->
<img src="images/logo.png" alt="Логотип">

Файл на уровень выше (две точки)

Если текущий файл находится во вложенной папке, а нужный — «снаружи», используем ../ (одна папка вверх): 

<!-- Из pages/blog.html в index.html -->
<a href="../index.html">На главную</a>

<!-- Из pages/blog.html в images/logo.png -->
<img src="../images/logo.png" alt="Логотип">

Два уровня выше

<!-- Из pages/sub/page.html на два уровня вверх -->
<a href="../../index.html">На главную</a>

4. Специальные обозначения

Символ Значение Пример
./ или ничего Текущая папка ./about.html = about.html
../ Одна папка выше ../index.html
../../ Две папки выше ../../index.html
/ (в начале) Корень сайта /images/logo.png
./ и ничего — работают одинаково. ./about.html и about.html — одно и то же. ./ явно показывает «в текущей папке», но обычно его опускают.

5. Абсолютные пути

Абсолютный путь — полный адрес файла. Начинается с протокола (https://) и содержит домен. 

<img src="https://example.com/images/cat.jpg" alt="Кот">
<a href="https://developer.mozilla.org">MDN</a>
Когда использовать абсолютные пути:
  • Ссылки на внешние сайты.
  • Картинки с чужих серверов (с разрешения!).
  • Подключение внешних библиотек (CDN).

6. Путь от корня сайта

Особый случай — путь, начинающийся с /. Он означает «от корня сайта», а не от текущей папки. 

<!-- Найдёт файл в корне сайта, независимо от того, где мы -->
<img src="/images/logo.png" alt="Логотип">
<a href="/about.html">О нас</a>

В чём разница

Смотрим на pages/blog.html:

Путь Куда указывает
images/logo.png pages/images/logo.png (относительно текущего)
../images/logo.png images/logo.png (на уровень выше)
/images/logo.png images/logo.png (от корня сайта)
Когда использовать путь от корня:
  • Когда файлы подключаются с сервера (не локально).
  • Когда страница может быть в любой папке — путь от корня всегда один и тот же.
  • Пример: <link rel="stylesheet" href="/css/style.css"> — работает с любой страницы.
Важно: путь от корня не работает локально при открытии файла через file://. Он работает только на сервере. Если ты открываешь HTML двойным кликом — /images/logo.png не найдётся.

7. Полный пример: как связать всё

Структура:

my-site/ ├── index.html ├── about.html ├── pages/ │ ├── blog.html ← мы здесь │ └── articles/ │ └── post.html ├── images/ │ └── logo.png └── css/ └── style.css

Из pages/blog.html

<!-- Ссылка на главную (../ = подняться в my-site/) -->
<a href="../index.html">Главная</a>

<!-- Ссылка на about.html (тоже через ../) -->
<a href="../about.html">О нас</a>

<!-- Ссылка на статью в подпапке (articles/) -->
<a href="articles/post.html">Статья</a>

<!-- Логотип из images/ (вверх и вниз) -->
<img src="../images/logo.png" alt="Логотип">

<!-- CSS из css/ -->
<link rel="stylesheet" href="../css/style.css">

Из pages/articles/post.html

<!-- Ссылка на главную (два уровня вверх) -->
<a href="../../index.html">Главная</a>

<!-- Ссылка на блог (на уровень вверх) -->
<a href="../blog.html">Блог</a>

<!-- Логотип (два уровня вверх и в images/) -->
<img src="../../images/logo.png" alt="Логотип">

8. Как проверить путь

Если файл не загружается:

  1. Открой DevTools (F12) → вкладка Network.
  2. Обнови страницу.
  3. Найди красные строки (ошибки 404).
  4. Посмотри, какой URL браузер пытался загрузить.
  5. Сравни с реальным путём к файлу.

9. Частые ошибки

Ошибка Почему не работает
src="images\logo.png" Обратный слэш — Windows-стиль, в HTML нужен /
href="example.com" Без протокола — браузер ищет файл example.com в текущей папке
href="page html.html" Пробел в имени — используй page-html.html или page_html.html
Забыть ../ Браузер ищет файл в текущей папке, а он на уровень выше
src="/images/logo.png" локально Путь от корня работает только на сервере
Русские буквы в имени файла Может сломаться на сервере — используй латиницу
Прописные буквы: Logo.PNG vs logo.png На Linux-серверах имена чувствительны к регистру

10. Правила хороших имён файлов

  • Только латиница — logo.png, а не логотип.png.
  • Только строчные буквы — image.jpg, а не Image.JPG.
  • Без пробелов — cat-photo.jpg, а не cat photo.jpg.
  • Без спецсимволов — кроме -, _, ..
  • Короткие и осмысленные — logo.png, а не CartInkaLogotip20260115final.png.
Почему: на сервере (Linux) имена чувствительны к регистру. Logo.PNG и logo.png — разные файлы. Если у тебя на Windows всё работает, на хостинге может сломаться.

11. Три способа проверить путь

Способ 1: вручную

Прочитай путь и мысленно пройди по нему от текущего файла:

  • ../ — выйди на уровень выше
  • ./ — останься на месте
  • folder/ — зайди в папку
  • file.ext — файл

Способ 2: через DevTools

Открой F12 → Network. Если файл не загрузился — увидишь 404. Наведи на строку — увидишь полный URL, который браузер запрашивал.

Способ 3: через исходник

В браузере нажми Ctrl+U (исходный код). Найди свой <img> или <a>. Браузер показывает исходный путь — сравни с реальным.

12. Практическое задание

Задание 1. «Создай структуру»

Создай файл 25-practice.html и такую структуру:

project/ ├── index.html ← этот файл ├── about.html ├── pages/ │ └── blog.html ├── images/ │ └── logo.png ← любая картинка └── css/ └── style.css

Задание 2. «Свяжи файлы»

Из index.html сделай ссылки:

  • На about.html.
  • На pages/blog.html.
  • На картинку images/logo.png (через <img>).
  • Подключи css/style.css через <link>.

Задание 3. «Из blog.html»

Открой pages/blog.html и сделай ссылки:

  • На главную (../index.html).
  • На about (../about.html).
  • На картинку (../images/logo.png).

Задание 4. «Проверь Network»

  • Открой F12 → Network.
  • Обнови страницу.
  • Найди все загруженные файлы. Если что-то 404 — исправь путь.

Задание 5. «Сломай и почини»

  • Напиши src="images\logo.png" (с обратным слэшем) — увидишь 404.
  • Напиши href="example.com" без протокола — увидишь, что браузер ищет файл в текущей папке.
  • Напиши src="/images/logo.png" локально — не найдётся (работает только на сервере).

Задание 6. «Три уровня»

  • Добавь pages/sub/page.html.
  • Из него сделай ссылку на главную (../../index.html).
  • Проверь, что переход работает.

13. Что запомнить из урока

  • Относительный путь — от текущего файла: file.html, folder/file.html.
  • ../ — на уровень выше. ../../ — на два.
  • / в начале — от корня сайта (работает только на сервере!).
  • Абсолютный путь — полный адрес с протоколом и доменом, для внешних ссылок.
  • Разделитель — только /, не \.
  • Имена файлов: латиница, строчные, без пробелов и спецсимволов.
  • Проверяй через DevTools → Network, если что-то не грузится.
  • Относительные пути — для своих файлов, абсолютные — для внешних.
