Урок 30. Итоговый проект — страница-резюме

1. Что будем делать

Ты прошёл 29 уроков. Пора собрать всё вместе в один проект — страницу-резюме. Это не просто упражнение: такую страницу можно использовать как реальное портфолио.

Что будет на странице:

  • Шапка с именем и навигацией.
  • Блок «Обо мне» — краткое описание.
  • Навыки — список.
  • Опыт — статьи/проекты.
  • Контакты — форма.
  • Подвал — копирайт.
Не копируй готовый код. Напиши свой, используя знания из уроков. Шаблон ниже — ориентир, а не «скопируй и сдай». Ценность — в том, что ты сам соберёшь всё вместе.

3. Структура страницы

Используй семантические теги:

<body>
├── <header>         ← шапка с именем и навигацией
│   ├── <h1>        ← имя
│   └── <nav>       ← навигация по разделам
│
├── <main>           ← основное содержимое
│   ├── <section>    ← «Обо мне»
│   ├── <section>    ← «Навыки»
│   ├── <section>    ← «Опыт» (с <article> внутри)
│   └── <section>    ← «Контакты» (форма)
│
└── <footer>         ← подвал

4. Мини-требования к проекту

Обязательно

  • ☐ <!DOCTYPE html> в первой строке.
  • ☐ <html lang="ru">.
  • ☐ <meta charset="UTF-8"> и viewport.
  • ☐ <title> — до 60 символов.
  • ☐ <meta name="description"> — 120–160 символов.
  • ☐ Один <h1>.
  • ☐ Семантические теги: <header>, <nav>, <main>, <section>, <footer>.
  • ☐ Навигация через якоря (#about, #skills и т.д.).
  • ☐ Хотя бы один список (<ul> или <ol>).
  • ☐ Хотя бы одно изображение с alt.
  • ☐ Форма обратной связи: имя, email, сообщение, кнопка.
  • ☐ Все поля с <label>.
  • ☐ Валидация: required, type="email".
  • ☐ Ссылки с осмысленным текстом.
  • ☐ Нет ошибок в W3C Validator.

По желанию (для продвинутых)

  • ☐ OG-теги для соцсетей.
  • ☐ <figure> с подписью к фото.
  • ☐ <time datetime> для дат.
  • ☐ <details> для FAQ.
  • ☐ <link rel="canonical">.
  • ☐ aria-label для иконок-кнопок.

5. Шаблон-ориентир

Ниже — пример структуры. Не копируй, а используй как ориентир. Заполни своим содержимым. 

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Иван Иванов — HTML-разработчик</title>
    <meta name="description" content="Резюме Ивана Иванова: HTML-разработчик. Навыки, опыт, контакты. Открыт к предложениям.">
    <meta name="author" content="Иван Иванов">

    <!-- Open Graph -->
    <meta property="og:title" content="Иван Иванов — HTML-разработчик">
    <meta property="og:description" content="Резюме: навыки, опыт, контакты.">
    <meta property="og:type" content="profile">

    <style>
        body { font-family: sans-serif; max-width: 800px; margin: 0 auto; padding: 20px; }
        header { border-bottom: 2px solid #333; padding-bottom: 20px; }
        nav ul { list-style: none; padding: 0; display: flex; gap: 16px; }
        nav a { text-decoration: none; color: #1565c0; }
        section { margin: 40px 0; }
        article { border-left: 3px solid #b5651d; padding-left: 16px; margin: 20px 0; }
        form { display: grid; gap: 12px; max-width: 400px; }
        label { font-weight: bold; }
        input, textarea, button { padding: 8px; font-size: 14px; }
        footer { border-top: 1px solid #ddd; padding-top: 20px; margin-top: 40px; text-align: center; color: #666; }
    </style>
</head>
<body>

    <header>
        <h1>Иван Иванов</h1>
        <p>HTML-разработчик · Москва</p>
        <nav>
            <ul>
                <li><a href="#about">Обо мне</a></li>
                <li><a href="#skills">Навыки</a></li>
                <li><a href="#experience">Опыт</a></li>
                <li><a href="#contact">Контакты</a></li>
            </ul>
        </nav>
    </header>

    <main>

        <section id="about">
            <h2>Обо мне</h2>
            <figure>
                <img src="photo.jpg" alt="Фото Ивана Иванова" width="150">
                <figcaption>Иван Иванов, 2026</figcaption>
            </figure>
            <p>Начинающий HTML-разработчик. Учусь создавать сайты с нуля.</p>
        </section>

        <section id="skills">
            <h2>Навыки</h2>
            <ul>
                <li>HTML5 — семантическая разметка</li>
                <li>Формы и валидация</li>
                <li>Доступность (a11y)</li>
                <li>Основы SEO</li>
            </ul>
        </section>

        <section id="experience">
            <h2>Опыт</h2>

            <article>
                <h3>Личный блог о кофе</h3>
                <time datetime="2025-09-01">Сентябрь 2025 — настоящее время</time>
                <p>Создал статический сайт с рецептами. HTML, CSS, адаптивная вёрстка.</p>
            </article>

            <article>
                <h3>Курс «HTML для начинающих»</h3>
                <time datetime="2025-06-01">Июнь 2025</time>
                <p>Прошёл 30 уроков, сделал итоговый проект.</p>
            </article>
        </section>

        <section id="contact">
            <h2>Контакты</h2>
            <p>Email: <a href="mailto:ivan@example.com">ivan@example.com</a></p>

            <form action="https://httpbin.org/post" method="post">
                <label for="name">Ваше имя:</label>
                <input type="text" id="name" name="name" required>

                <label for="email">Email:</label>
                <input type="email" id="email" name="email" required>

                <label for="message">Сообщение:</label>
                <textarea id="message" name="message" rows="4" required></textarea>

                <button type="submit">Отправить</button>
            </form>
        </section>

    </main>

    <footer>
        <p>&copy; 2026 Иван Иванов. Сделано на чистом HTML.</p>
    </footer>

</body>
</html>

6. Пошаговый план работы

  1. Начни с каркаса. Скопируй шаблон из урока 3 (DOCTYPE + head + body).
  2. Заполни <head>. Title, description, OG-теги.
  3. Сделай шапку. <header> + <h1> + <nav> с якорями.
  4. Добавь секции. <main> → 4 <section>.
  5. Наполни контентом. Обо мне, навыки, опыт, контакты.
  6. Добавь форму. С <label>, required, type="email".
  7. Добавь подвал. <footer> с копирайтом.
  8. Проверь в браузере. Открой, полистай, покликай.
  9. Проверь валидатором. W3C → исправь ошибки.
  10. Проверь в DevTools. F12 → Elements → посмотри структуру.
  11. Проверь клавиатурой. Tab по всем ссылкам и полям.
  12. Загрузи на GitHub Pages или Netlify. Получи ссылку.

7. Чек-лист перед «сдачей»

  • Каркас: DOCTYPE, html lang, head с charset и viewport
  • Title — до 60 символов, уникальный
  • Meta description — 120–160 символов
  • Один h1 на страницу
  • Иерархия заголовков: h1 → h2 → h3 без пропусков
  • Семантические теги: header, nav, main, section, article, footer
  • Навигация с якорями работает
  • Все ссылки с осмысленным текстом
  • Все img с alt (декоративные — с alt="")
  • Все поля формы с label
  • Валидация: required, type="email", minlength
  • Форма отправляется (проверь через httpbin)
  • Все id уникальны
  • Все теги закрыты
  • Нет ошибок в W3C Validator
  • DevTools → Console: нет красных ошибок
  • DevTools → Network: нет 404
  • Работает с клавиатуры (Tab, Enter)
  • Lighthouse Accessibility ≥ 90
  • Страница адаптивна (открой на телефоне)
