Урок 23. <div> и <span>

1. Что такое <div> и <span>

Это универсальные контейнеры без смысла. Они не говорят, что внутри — просто «коробка». Нужны для:

  • Группировки элементов для CSS-стилизации.
  • Группировки для JavaScript (найти, изменить).
  • Обёртки, когда семантический тег не подходит.
Тег Тип Занимает Где использовать
<div> Блочный Всю ширину Группировка крупных блоков
<span> Строчный Только по содержимому Выделение части текста

2. Блочные vs строчные элементы

Это фундаментальное различие в HTML. Запомни его.

Блочные (block)

  • Занимают всю ширину родителя.
  • Начинаются с новой строки.
  • Можно задать width, height, margin, padding со всех сторон.
  • Примеры: <div>, <p>, <h1>, <ul>, <section>.
Два блока div — каждый на новой строке, во всю ширину:
Первый блок div
Второй блок div

Строчные (inline)

  • Занимают только ширину содержимого.
  • Идут в строке с другим текстом.
  • width и height не работают.
  • Вертикальные margin и padding работают частично (визуально не сдвигают строки).
  • Примеры: <span>, <a>, <strong>, <em>, <code>.

div vs span — рамки одинаковой толщины:

4. Тег <div> — блочный контейнер

Основной инструмент для построения макета. Используется, когда нужен крупный блок без семантики. 

<div class="card">
    <h2>Заголовок карточки</h2>
    <p>Описание...</p>
    <button>Кнопка</button>
</div>

Где использовать <div>

  • Обёртка для сетки: <div class="grid"> с дочерними <div class="grid-item">.
  • Карточка товара: если нет семантического тега для карточки.
  • Контейнер с CSS: например, центрирование контента.
  • Обёртка для позиционирования: position: relative.

Где НЕ использовать <div>

  • Шапка → <header>
  • Меню → <nav>
  • Основной контент → <main>
  • Статья → <article>
  • Раздел с заголовком → <section>
  • Боковая панель → <aside>
  • Подвал → <footer>
Если есть семантический тег — используй его, а не <div>.

5. Тег <span> — строчный контейнер

Используется для выделения части текста без разрыва строки. Например, чтобы покрасить одно слово или изменить шрифт. 

<p>Цена: <span class="price">500 ₽</span> за штуку</p>
.price {
    color: green;
    font-weight: bold;
    font-size: 1.2em;
}
Результат:

Цена: 500 ₽ за штуку

Где использовать <span>

  • Выделить одно слово или фразу в тексте.
  • Изменить цвет, шрифт части текста.
  • Обернуть текст для JavaScript-манипуляции.
  • Иконки внутри текста (например, валюты).
Правило: если нужен смысл («важно», «акцент», «удалено») — используй семантический тег (<strong>, <em>, <mark>, <del>). <span> — только когда нужна стилизация без смысла.

6. Когда div, когда section, когда article

Это частый вопрос. Таблица-помощник:

Что за блок Тег
Шапка сайта/статьи <header>
Основное меню <nav>
Главное содержимое страницы <main>
Тематический раздел с заголовком <section>
Самодостаточная единица (пост, товар, новость) <article>
Боковая панель <aside>
Подвал <footer>
Картинка с подписью <figure>
Просто обёртка для CSS <div>
Просто часть текста для стилизации <span>

7. Пример: «дивовый суп» vs семантика

Плохо: всё через div

<div class="header">
    <div class="logo">Мой блог</div>
    <div class="nav">
        <div class="nav-item"><a href="/">Главная</a></div>
        <div class="nav-item"><a href="/blog">Блог</a></div>
    </div>
</div>
<div class="content">
    <div class="article">
        <div class="article-title">Как варить кофе</div>
        <div class="article-body">Текст...</div>
    </div>
</div>
<div class="footer">&copy; 2026</div>

Проблемы:

  • Непонятно, где шапка, а где контент.
  • Screen reader не различает регионы.
  • Поисковик не понимает структуру.

Хорошо: семантика + div для мелочей

<header>
    <h1>Мой блог</h1>
    <nav>
        <a href="/">Главная</a>
        <a href="/blog">Блог</a>
    </nav>
</header>
<main>
    <article>
        <h2>Как варить кофе</h2>
        <p>Текст...</p>
    </article>
</main>
<footer>
    &copy; 2026
</footer>

Обрати внимание: даже в «хорошем» примере могут быть <div> — например, для карточки товара в сетке, обёртки для CSS. Это нормально. Главное — смысловые блоки сделаны семантически.

8. Группировка для CSS

Классический пример: обёртка для сетки.

<div class="grid">
    <div class="card">Карточка 1</div>
    <div class="card">Карточка 2</div>
    <div class="card">Карточка 3</div>
</div>
.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 16px;
}

.card {
    background: white;
    border: 1px solid #ddd;
    padding: 16px;
}

Здесь <div> — правильный выбор. Карточки — просто визуальные блоки без семантического значения. Это не статья и не раздел.

9. Группировка для JavaScript

<span id="count">0</span> — счётчик, который обновляется через JS. Без <span> не обойтись — нужен строчный контейнер вокруг числа. 

<p>Корзина: <span id="cart-count">0</span> товаров</p>

<script>
    document.getElementById('cart-count').textContent = 5;
</script>

Корзина: 0 товаров.

10. Вложенность div и span

<div> может содержать <span>, но не наоборот. Строчный элемент не может содержать блочный. 

<!-- ПРАВИЛЬНО -->
<div>
    <p>Текст с <span>выделением</span></p>
</div>

<!-- НЕПРАВИЛЬНО: span не может содержать div -->
<span>
    <div>блок</div>
</span>
Почему нельзя: браузер «вытолкнет» <div> из <span>, потому что блочный элемент не может быть внутри строчного. Это сломает твою структуру.

11. div и span в контексте других элементов

Что можно класть внутри:

Внутрь чего Можно класть
<div> Всё что угодно (блочное и строчное)
<span> Только строчное (текст, <strong>, <em>, <a>, другой <span>)
<p> Только строчное (то же, что и span)
<h1>–<h6> Только строчное

12. Стилизация div и span

Блочные и строчные элементы по-разному принимают CSS:

Свойство <div> <span>
width, height ✅ Работает ❌ Не работает
margin (все стороны) ✅ Работает ⚠️ Только по горизонтали
padding ✅ Работает ⚠️ Работает, но не сдвигает строки
border ✅ Работает ✅ Работает
background ✅ Работает ✅ Работает
text-align ✅ Работает ❌ Не работает
Можно изменить поведение: CSS-свойство display позволяет сделать <div> строчным (display: inline) или <span> блочным (display: block). Но семантически это не меняет смысла — это просто визуальный трюк.

13. Частые ошибки

Ошибка Почему плохо
Использовать <div> вместо семантических тегов «Дивовый суп» — плохо для a11y и SEO
Вкладывать <div> в <span> Невалидно, браузер вытолкнет
Использовать <span> для блочных элементов То же самое
Пытаться задать width у <span> Не работает без display: inline-block
Забыть class у <div> Бесполезная обёртка — нечем стилизовать
Оборачивать каждое слово в <span> Мусор в коде, лучше <strong>/<em>

14. Практическое задание

Задание 1. «Карточки товаров»

Создай файл 23-practice.html. Сделай 3 карточки товаров через <div>:

  • Общий контейнер <div class="grid">.
  • Каждая карточка — <div class="card"> с заголовком, ценой и кнопкой.
  • CSS: сетка 3 колонки, отступы, рамки.

Задание 2. «Выделение в тексте»

  • Напиши абзац текста о чём угодно.
  • Выдели <span> три разных слова: одно — зелёным, другое — красным, третье — жирным.
  • Используй class и CSS, а не инлайн-стили.

Задание 3. «Счётчик на JS»

  • Сделай кнопку и текст «Кликов: <span id="count">0</span>».
  • При клике на кнопку число увеличивается на 1 (через JavaScript).
  • Проверь, что счётчик работает.

Задание 4. «div или section?»

  • Возьми 5 блоков на странице: шапка, меню, статья, «читайте также», подвал.
  • Определи, какой семантический тег подходит для каждого.
  • Сделай страницу с правильными тегами. <div> — только для обёрток.

Задание 5. «Сломай и почини»

  • Вложи <div> в <span>. Открой DevTools — увидишь, как браузер перестроил DOM.
  • Попробуй задать width: 200px у <span> — увидишь, что не работает.
  • Добавь display: inline-block к <span> — теперь width заработает.

15. Что запомнить из урока

  • <div> — блочный контейнер без смысла.
  • <span> — строчный контейнер без смысла.
  • Блочные — вся ширина, новая строка. Строчные — по содержимому, в строке.
  • <div> — для обёрток, сеток, карточек.
  • <span> — для выделения части текста.
  • Если есть семантический тег — используй его, а не <div>.
  • <div> может содержать всё, <span> — только строчное.
  • У <span> не работает width, height, text-align без display: inline-block.
  • Семантика ≠ замена div на section везде. Для чисто декоративных обёрток — <div>.
