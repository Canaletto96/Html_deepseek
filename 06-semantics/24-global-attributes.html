Урок 24. Глобальные атрибуты

1. Что такое глобальные атрибуты

Глобальные атрибуты — это атрибуты, которые можно применять к любому HTML-тегу. Они не привязаны к конкретному элементу (в отличие от href у <a> или src у <img>).

Самые используемые:

Атрибут Для чего Пример
id Уникальный идентификатор элемента id="header"
class Группа для CSS / JS class="btn btn-primary"
style CSS прямо в теге style="color: red"
title Подсказка при наведении title="Это подсказка"
data-* Свои данные для JS data-user-id="123"
hidden Скрыть элемент hidden
lang Язык содержимого lang="ru"
dir Направление текста dir="rtl"
tabindex Порядок фокуса tabindex="0"
contenteditable Разрешить редактирование contenteditable="true"
draggable Разрешить перетаскивание draggable="true"
spellcheck Проверка орфографии spellcheck="false"

2. Атрибут id — уникальный идентификатор

id — это «имя» элемента на странице. Должен быть уникальным — один id = один элемент. 

<h1 id="main-title">Заголовок</h1>
<nav id="main-nav">...</nav>
<form id="login-form">...</form>

Зачем нужен id

  • Якоря: <a href="#main-title"> — переход к элементу.
  • CSS: #main-title { color: red; }.
  • JavaScript: document.getElementById('main-title').
  • label: <label for="email"> → <input id="email">.
Правила id:
  • Должен быть уникален на странице.
  • Не должен содержать пробелов.
  • Чувствителен к регистру (id="Header" ≠ id="header").
  • Может начинаться с буквы, цифры, _, -.
  • Не должен начинаться с цифры (невалидно).

Пример: якорь

<a href="#section-2">Перейти к разделу 2</a>

...

<h2 id="section-2">Раздел 2</h2>

3. Атрибут class — группа для стилей

class — это «категория» элемента. Может быть у многих элементов, у одного элемента может быть несколько классов через пробел. 

<p class="text">Обычный текст</p>
<p class="text important">Важный текст</p>
<p class="text highlight">Выделенный текст</p>
.text { font-size: 16px; }
.important { color: red; }
.highlight { background: yellow; }

id vs class

id class
Уникальность Один на страницу Может повторяться
Количество Один у элемента Сколько угодно (через пробел)
CSS-селектор #id .class
JS getElementById() getElementsByClassName(), querySelectorAll()
Когда использовать Якоря, label, уникальные элементы Стили, группировка
Современная практика: для CSS — почти всегда class. id — для якорей, JS-селекторов и label. Не используй id для стилизации (это усложняет переопределение).

4. Атрибут style — CSS прямо в теге

Позволяет задать CSS-стили прямо в HTML-теге. Называется инлайн-стиль. 

<p style="color: red; font-size: 20px;">Красный текст</p>
Результат:

Красный текст

Когда использовать style

  • Быстрая правка — «на 5 секунд», чтобы проверить.
  • Динамические стили из JavaScript (например, element.style.color = 'red').
  • Email-письма — там CSS-файлы не работают, нужны инлайн-стили.
Не используй style постоянно!
  • Стили смешиваются с HTML — код сложно читать.
  • Нельзя кэшировать — загружается с каждым HTML.
  • Сложно переопределять — инлайн-стиль имеет высокий приоритет.
  • Не работает для :hover, медиа-запросов.
Используй class + отдельный CSS-файл. style — только для экстренных случаев.

5. Атрибут title — подсказка

Показывает всплывающую подсказку при наведении мыши. Работает почти на всех элементах. 

<abbr title="HyperText Markup Language">HTML</abbr>
<a href="https://example.com" title="Перейти на главную">Главная</a>
<button title="Сохранить изменения">💾</button>
Результат (наведи мышью):

HTML — Главная —

Ограничения title:
  • Не работает на тач-устройствах (нет hover).
  • Плохо воспринимается screen reader'ами (читают как часть текста).
  • Не используй вместо текста ссылки — если что-то важно, пиши это в содержимом.

6. Атрибут data-* — свои данные для JS

Позволяет хранить любые данные прямо в HTML-атрибутах. Имя начинается с data-, дальше — что угодно. 

<div data-user-id="123" data-role="admin" data-last-login="2026-01-15">
    Иван Иванов
</div>

<button data-action="delete" data-item-id="42">Удалить</button>

В JavaScript эти данные доступны через dataset:

const btn = document.querySelector('button');
btn.dataset.action;    // "delete"
btn.dataset.itemId;    // "42" (дефис → camelCase)
Результат (нажми кнопку — данные выводятся в alert):
Правила data-*:
  • Имя после data- — только строчные латинские буквы, цифры, дефис.
  • Не используй data- для данных, которые важны для SEO (поисковики их не индексируют).
  • В JS: data-user-id → dataset.userId.

Зачем data-* на практике

  • ID для JS-обработчиков: какая кнопка нажата.
  • Настройки компонента: data-theme="dark".
  • Параметры анимации: data-speed="500".
  • Трекеры аналитики: data-event="click-buy".

7. Атрибут hidden — скрыть элемент

Полностью скрывает элемент из отображения и из дерева доступности. Это булев атрибут — значение не нужно. 

<p hidden>Этот текст не видно на странице.</p>
Результат (первый абзац скрыт, второй виден):

Этот текст НЕ виден.

Этот текст виден. Между ними нет пустого места.

В отличие от display: none, hidden:

  • Удаляет элемент из дерева доступности (screen reader не читает).
  • Не участвует в tab-навигации.
  • Обычно эквивалентен display: none, но некоторые браузеры могут переопределять.

hidden vs CSS display: none

hidden style="display: none"
Скрывает Да Да
Семантика «скрыт» «не отображается»
Переопределяется CSS? Да, но не рекомендуется Да (это и есть CSS)
Когда использовать Контент, который должен быть скрыт по смыслу Скрыть визуально, оставив в DOM

8. Атрибут lang — язык содержимого

Указывает, на каком языке содержимое элемента. Обычно ставится на <html>, но можно — на отдельные фрагменты. 

<html lang="ru">
...
<p lang="en">Hello, world!</p>
<p lang="fr">Bonjour le monde!</p>

Зачем:

  • Screen reader читает правильным голосом.
  • Браузер корректно переносит слова, ставит кавычки, проверяет орфографию.
  • Поисковики понимают, на каком языке страница.

9. Атрибут dir — направление текста

Определяет направление текста: слева направо (ltr) или справа налево (rtl). 

<p dir="ltr">Обычный текст слева направо</p>
<p dir="rtl">مرحبا بالعالم! (арабский)</p>
<p dir="auto">Автоопределение направления</p>
Результат:

Обычный текст слева направо

مرحبا بالعالم! (арабский)

Auto: English text

مرحبا بالعالم

dir="auto" — браузер сам определяет направление по первому символу. Удобно для пользовательского контента (комментарии, посты).

10. Атрибут tabindex — порядок фокуса

Управляет порядком, в котором элементы получают фокус при нажатии Tab.

Значение Что означает
0 Естественный порядок (как в DOM)
-1 Не фокусируется через Tab, но можно через JS
1, 2, 3... Приоритетный порядок (обычно не использовать!) 
<!-- Сделать нефокусируемый элемент фокусируемым -->
<div tabindex="0">Этот div теперь можно выбрать Tab'ом</div>

<!-- Убрать кнопку из tab-навигации, но оставить кликабельной -->
<button tabindex="-1">Скрыта из Tab</button>
Не используй tabindex больше 0! Это ломает естественную навигацию и путает пользователей. Оставляй tabindex="0" или -1, а порядок — по DOM.

11. contenteditable — редактирование

Делает элемент редактируемым, как поле ввода. 

<div contenteditable="true">
    Этот текст можно редактировать прямо на странице!
</div>
Результат (кликни и попробуй изменить):
Этот текст можно редактировать. Кликни и попробуй изменить!

Используется в:

  • Визуальных редакторах (WYSIWYG).
  • Заметках и to-do-списках.
  • Демо-площадках.

13. Частые ошибки

Ошибка Почему плохо
Два одинаковых id на странице Невалидно, getElementById вернёт только первый
Использовать id для стилизации Высокий приоритет в CSS, сложно переопределить
Злоупотреблять style Смешивает HTML и CSS, сложно поддерживать
Использовать title вместо label Не работает на мобильных и в screen reader'ах
tabindex="5" и выше Ломает навигацию, путает пользователей
Хранить секреты в data-* Видны через DevTools
class с пробелами в имени Пробел — разделитель классов, не часть имени

15. Что запомнить из урока

  • Глобальные атрибуты работают на любом теге.
  • id — уникальный, один на страницу. Для якорей, JS, label.
  • class — повторяемый, может быть несколько. Для CSS.
  • style — инлайн-CSS. Только для экстренных случаев.
  • title — подсказка при наведении. Не для важной информации.
  • data-* — свои данные для JS, доступны через dataset.
  • hidden — скрыть элемент из DOM и из screen reader'ов.
  • lang — язык содержимого (ru, en).
  • dir — направление текста (ltr, rtl, auto).
  • tabindex — порядок фокуса. Только 0 или -1.
  • contenteditable — редактирование прямо на странице.
  • draggable — перетаскивание элемента.
  • spellcheck — проверка орфографии.
  • accesskey — горячая клавиша (использовать редко).
  • translate — переводить ли через Google Translate.

17. id vs class — когда что

Ситуация Используй Почему
Якорь для ссылки #section id Ссылка работает только с id
Связка label + input id for работает только с id
Стилизация карточек, кнопок class Много элементов — один класс
JS-селектор id или class id — для уникальных, class — для групп
Форма (поля) name + id name для отправки, id для label
Правило: для CSS — почти всегда class. id — для якорей, label, JS-селекторов уникальных элементов. Не используй id для стилизации — это усложняет переопределение.

18. Частые ошибки (расширенно)

Ошибка Что будет Как исправить
Два одинаковых id Валидатор ругается, getElementById вернёт первый Сделай id уникальным, для группы — class
id="my header" (с пробелом) Пробел разрывает имя, работает только my id="my-header" или id="myHeader"
id="123" (начинается с цифры) Валидатор ругается id="item-123"
class="btn btn" Дублирование класса class="btn"
Много style атрибутов Код сложно читать Выноси в CSS-файл через class
tabindex="5" Ломает навигацию Используй 0 или -1
aria-hidden на фокусируемом элементе Пользователь с клавиатурой «теряет» элемент Не скрывай фокусируемое от screen reader'а
Секреты в data-* Видны через DevTools Храни секреты на сервере
