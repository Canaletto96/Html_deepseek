Урок 16. Продвинутые таблицы

1. Зачем нужна структура

В прошлом уроке мы строили таблицы «в лоб»: <tr>, <td>, <th>. Для маленьких таблиц этого достаточно. Но для больших и семантически правильных нужна структура.

В HTML таблицу можно разделить на три смысловые зоны:

Тег Название Что содержит
<thead> table head Шапку: заголовки столбцов
<tbody> table body Основные данные
<tfoot> table foot Подвал: итоги, суммы, примечания
Зачем это нужно:
  • Screen reader'ы понимают, где шапка, а где данные.
  • CSS можно стилизовать каждую часть отдельно.
  • JavaScript удобно работать с отдельными зонами.
  • При печати <thead> повторяется на каждой странице.

2. Тег <thead> — шапка

Содержит строки с <th> — заголовки столбцов.

<thead>
    <tr>
        <th scope="col">Товар</th>
        <th scope="col">Цена</th>
        <th scope="col">Количество</th>
    </tr>
</thead>

3. Тег <tbody> — тело

Основные данные таблицы — строки с <td>.

<tbody>
    <tr>
        <td>Кофе</td>
        <td>500 ₽</td>
        <td>2</td>
    </tr>
    <tr>
        <td>Чай</td>
        <td>300 ₽</td>
        <td>1</td>
    </tr>
</tbody>
В одной таблице может быть несколько <tbody> — например, для группировки данных по категориям. Это валидно.

4. Тег <tfoot> — подвал

Итоги, суммы, примечания. Часто содержит «Итого».

<tfoot>
    <tr>
        <td colspan="2">Итого:</td>
        <td>800 ₽</td>
    </tr>
</tfoot>

5. Полный пример структурированной таблицы

<table>
    <caption>Таблица 1. Заказ</caption>

    <thead>
        <tr>
            <th scope="col">Товар</th>
            <th scope="col">Цена</th>
            <th scope="col">Количество</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>Кофе</td>
            <td>500 ₽</td>
            <td>2</td>
        </tr>
        <tr>
            <td>Чай</td>
            <td>300 ₽</td>
            <td>1</td>
        </tr>
    </tbody>

    <tfoot>
        <tr>
            <td colspan="2">Итого:</td>
            <td>1300 ₽</td>
        </tr>
    </tfoot>
</table>
Результат:
Таблица 1. Заказ
Товар Цена Количество
Кофе 500 ₽ 2
Чай 300 ₽ 1
Итого: 1300 ₽

6. Порядок тегов

По стандарту порядок такой: <caption> → <colgroup> → <thead> → <tbody> → <tfoot>.

Интересный факт: в HTML5 <tfoot> может стоять как до, так и после <tbody>. Раньше по стандарту он должен был идти перед <tbody>. Сейчас браузеры оба варианта принимают. Но пиши после — так логичнее и понятнее.

7. Тег <colgroup> и <col> — группы столбцов

<colgroup> — контейнер для <col>. Позволяет задать стили целым столбцам, не трогая каждую ячейку. 

<table>
    <colgroup>
        <col style="background: #fff8e1;">
        <col style="background: #e8f5e9;">
        <col span="2" style="background: #e3f2fd;">
    </colgroup>
    <tr>
        <th>Столбец 1</th>
        <th>Столбец 2</th>
        <th>Столбец 3</th>
        <th>Столбец 4</th>
    </tr>
    <tr>
        <td>Данные 1</td>
        <td>Данные 2</td>
        <td>Данные 3</td>
        <td>Данные 4</td>
    </tr>
</table>
Результат (столбцы с разными фонами):
Столбец 1 Столбец 2 Столбец 3 Столбец 4
Данные 1 Данные 2 Данные 3 Данные 4

Атрибут span у <col>

<col span="N"> — стиль применяется к N столбцам. Например, <col span="2"> — к двум подряд идущим.

Атрибуты <col>

Атрибут Значения Описание
span Число Сколько столбцов охватывает
style CSS Стили для столбца
Что НЕ работает в col: через <col> можно задать только background, border, width, visibility. Нельзя задать padding, font, color — для этого придётся использовать <td> или <th>.

8. Зачем нужен colgroup на практике

Пример: таблица с фиксированной шириной столбцов.

<table>
    <colgroup>
        <col style="width: 60%;">
        <col style="width: 20%;">
        <col style="width: 20%;">
    </colgroup>
    <!-- строки... -->
</table>

Без colgroup пришлось бы задавать style="width: 60%" каждой ячейке первого столбца. С colgroup — один раз.

9. Несколько <tbody> — группировка данных

Можно разбить данные на группы с отдельными «подшапками»:

<table>
    <thead>
        <tr>
            <th>Категория</th>
            <th>Товар</th>
            <th>Цена</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <th colspan="3">Напитки</th>
        </tr>
        <tr>
            <td></td>
            <td>Кофе</td>
            <td>500 ₽</td>
        </tr>
        <tr>
            <td></td>
            <td>Чай</td>
            <td>300 ₽</td>
        </tr>
    </tbody>

    <tbody>
        <tr>
            <th colspan="3">Еда</th>
        </tr>
        <tr>
            <td></td>
            <td>Бутерброд</td>
            <td>250 ₽</td>
        </tr>
    </tbody>
</table>
Результат:
Категория Товар Цена
Напитки
Кофе 500 ₽
Чай 300 ₽
Еда
Бутерброд 250 ₽
Совет: когда используешь <tbody> для группировки, добавляй CSS-классы (class="group-heading") — так проще стилизовать.

10. Стилизация через CSS

thead {
    background: #333;
    color: #fff;
}

tfoot {
    background: #f5f5f5;
    font-weight: bold;
}

tbody tr:nth-child(even) {
    background: #f9f9f9;
}

tbody tr:hover {
    background: #fff8e1;
}
Результат (стилизованная таблица):
Заказ
Товар Цена Кол-во
Кофе 500 ₽ 2
Чай 300 ₽ 1
Какао 400 ₽ 1
Итого: 1700 ₽

11. Sticky-заголовок

Для длинных таблиц удобно «приклеить» шапку, чтобы она оставалась видимой при прокрутке: 

thead th {
    position: sticky;
    top: 0;
    background: #333;
    color: #fff;
    z-index: 1;
}
Прокрути таблицу вниз (шапка останется видимой):
Товар Цена
Кофе500 ₽
Чай300 ₽
Какао400 ₽
Сок200 ₽
Вода100 ₽
Молоко150 ₽
Кефир180 ₽

12. Адаптивные таблицы для мобильных

Таблицы на мобильных — боль. Самый простой способ — горизонтальная прокрутка: 

<div style="overflow-x: auto;">
    <table>...</table>
</div>

Ещё вариант — «карточки»: на мобильных каждая строка выглядит как блок. Но это уже CSS-приём, а не HTML.

13. Доступность (a11y) таблиц

Правила для семантически правильной таблицы:

  1. <caption> — всегда, если таблица смысловая.
  2. <th> — для всех заголовков (не «жирный td»).
  3. scope="col" или scope="row" — уточнить направление.
  4. <thead>, <tbody>, <tfoot> — структура.
  5. Пустые ячейки — вставляй &nbsp;, а не оставляй пустыми.
<table>
    <caption>Таблица 1. Сравнение тарифов</caption>
    <thead>
        <tr>
            <th scope="col">Тариф</th>
            <th scope="col">Цена</th>
            <th scope="col">Место</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <th scope="row">Базовый</th>
            <td>500 ₽</td>
            <td>1 ГБ</td>
        </tr>
        <tr>
            <th scope="row">Стандарт</th>
            <td>900 ₽</td>
            <td>5 ГБ</td>
        </tr>
    </tbody>
</table>

14. Частые ошибки

Ошибка Почему плохо
Использовать <td> вместо <th> для заголовков Screen reader не понимает структуру
Забыть scope Заголовки «висят в воздухе»
Не использовать <thead> и <tbody> Теряется семантика, сложнее стилизовать
Вкладывать <tfoot> между <tbody> Невалидно: только до или после <tbody>
Несколько <caption> Разрешён только один
Использовать <col> для padding или font Работает только для фона, рамки, ширины

  • Помести <tfoot> между двумя <tbody> — проверь валидатором.
  • Убери scope у <th> — попробуй прочитать таблицу через screen reader, увидишь разницу.
  • Попробуй задать через <col> свойство padding: 20px; — убедись, что не работает.

17. Что запомнить из урока

  • Три структурных тега: <thead> (шапка), <tbody> (данные), <tfoot> (итоги).
  • Порядок: caption → colgroup → thead → tbody → tfoot.
  • Можно использовать несколько <tbody> для группировки данных.
  • <colgroup> + <col> — для стилизации столбцов (только фон, рамки, ширина).
  • <col span="N"> — охватить N столбцов одной настройкой.
  • Sticky-заголовок: position: sticky; top: 0; на thead th.
  • Для доступности: caption + th + scope = обязательный минимум.
  • Адаптивность: overflow-x: auto для горизонтальной прокрутки.
