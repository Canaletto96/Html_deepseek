Урок 15. Таблицы — основы

1. Зачем нужны таблицы

Таблицы в HTML — для табличных данных: расписаний, цен, характеристик товаров, сравнений. Это НЕ инструмент вёрстки (как было в 90-е), а семантический тег для структурированной информации.

Не используй таблицы для вёрстки макета (шапка, сайдбар, контент). Для этого есть flexbox и grid в CSS. Таблицы — только для данных.

2. Базовые теги

Тег Название Что создаёт
<table> table Контейнер таблицы
<tr> table row Строка таблицы
<td> table data Ячейка с данными
<th> table header Ячейка-заголовок
<caption> caption Подпись таблицы

3. Простейшая таблица

<table>
    <tr>
        <th>Имя</th>
        <th>Возраст</th>
        <th>Город</th>
    </tr>
    <tr>
        <td>Иван</td>
        <td>28</td>
        <td>Москва</td>
    </tr>
    <tr>
        <td>Мария</td>
        <td>34</td>
        <td>Санкт-Петербург</td>
    </tr>
</table>
Результат:
Имя Возраст Город
Иван 28 Москва
Мария 34 Санкт-Петербург

Что важно понимать

  • Таблица строится по строкам (<tr>), а не по столбцам.
  • В каждой строке одинаковое количество ячеек — это и есть столбцы.
  • <th> — для заголовков (жирный, по центру), <td> — для данных.
  • Порядок ячеек в строке = порядок столбцов.

4. Атрибуты <table>

Атрибут Значения Описание
border Число Толщина рамки (устарел, используй CSS border)
cellpadding Число Отступ внутри ячейки (устарел, используй CSS padding)
cellspacing Число Расстояние между ячейками (устарел, используй CSS border-spacing)
width Число или % Ширина таблицы (устарел, используй CSS)
Современный подход: все визуальные атрибуты таблиц устарели. Используй CSS: border, padding, border-collapse. В HTML оставь только структуру.

5. Тег <caption> — подпись таблицы

<caption> — название таблицы. Идёт сразу после <table> и до строк. 

<table>
    <caption>Таблица 1. Сотрудники компании</caption>
    <tr>
        <th>Имя</th>
        <th>Должность</th>
    </tr>
    <tr>
        <td>Иван</td>
        <td>Разработчик</td>
    </tr>
</table>
Результат:
Таблица 1. Сотрудники компании
Имя Должность
Иван Разработчик
Зачем нужен caption: screen reader читает его перед таблицей, объясняя, о чём она. Это как alt для картинки — только для таблицы.

6. Объединение ячеек: colspan и rowspan

Иногда нужно, чтобы ячейка занимала несколько столбцов или несколько строк.

Атрибут Что делает Пример
colspan Растянуть по горизонтали (объединить столбцы) colspan="2" — занять 2 столбца
rowspan Растянуть по вертикали (объединить строки) rowspan="2" — занять 2 строки

Пример colspan

<table>
    <tr>
        <th colspan="2">Личные данные</th>
    </tr>
    <tr>
        <td>Имя:</td>
        <td>Иван</td>
    </tr>
    <tr>
        <td>Возраст:</td>
        <td>28</td>
    </tr>
</table>
Результат (первая ячейка занимает 2 столбца):
Личные данные
Имя: Иван
Возраст: 28

Пример rowspan

<table>
    <tr>
        <th>День</th>
        <th>Предмет</th>
    </tr>
    <tr>
        <td rowspan="2">Понедельник</td>
        <td>Математика</td>
    </tr>
    <tr>
        <td>Физика</td>
    </tr>
</table>
Результат (Понедельник занимает 2 строки):
День Предмет
Понедельник Математика
Физика
Правило подсчёта: когда используешь colspan/rowspan, в следующей строке может быть меньше <td>, потому что ячейка уже «занята» соседней. Считай внимательно, иначе таблица «поедет».

7. Ячейки-заголовки: th vs td

Разница — в смысле, а не только в стиле:

<th> <td>
Смысл Заголовок строки или столбца Ячейка с данными
Внешний вид по умолчанию Жирный, по центру Обычный текст, влево
Screen reader Читает как заголовок, потом данные Просто данные
Не делай «жирные td» вместо th! Используй <th> там, где это семантически заголовок — screen reader и поисковики поймут структуру.

8. Атрибут scope для th

scope уточняет, к чему относится заголовок <th>:

Значение Что означает
col Заголовок столбца
row Заголовок строки
colgroup Заголовок для группы столбцов
rowgroup Заголовок для группы строк 
<table>
    <tr>
        <th scope="col">Товар</th>
        <th scope="col">Цена</th>
    </tr>
    <tr>
        <th scope="row">Кофе</th>
        <td>500 ₽</td>
    </tr>
</table>
Результат:
Товар Цена
Кофе 500 ₽
Зачем scope: screen reader читает не только значение ячейки, но и её заголовки. Без scope он не всегда понимает, к чему относится <th>. С scope="col" — точно столбец, с scope="row" — строка.

9. Стилизация таблиц через CSS

По умолчанию таблицы выглядят «коряво». Базовые стили:

table {
    border-collapse: collapse;  /* убрать двойные рамки */
    width: 100%;
    margin: 16px 0;
}

th, td {
    border: 1px solid #ddd;
    padding: 10px 12px;
    text-align: left;
}

th {
    background: #f5f5f5;
    font-weight: bold;
}
Главное свойство: border-collapse: collapse. Без него у каждой ячейки свои рамки, между ними пробелы. С ним — единая таблица.

Полосатая таблица (zebra)

tr:nth-child(even) {
    background: #f9f9f9;
}
Результат:
Товар Цена
Кофе 500 ₽
Чай 300 ₽
Какао 400 ₽
Сок 200 ₽

10. Что будет без CSS

По умолчанию браузер рисует таблицу без рамок и с минимальным форматированием:

Без CSS:
Имя Возраст
Иван 28
Мария 34

Ячейки на самом деле есть, но рамок нет — их надо добавлять через CSS.

11. Частые ошибки

Ошибка Почему плохо
Использовать таблицу для вёрстки макета Плохо для SEO, a11y и адаптивности. Для вёрстки — CSS grid/flex
Разное число ячеек в строках без colspan/rowspan Таблица «поедет», структура сломается
Использовать border, cellpadding и др. Устаревшие атрибуты, вместо них — CSS
Забыть <caption> Screen reader не понимает, о чём таблица
Не использовать scope для <th> Незрячим сложнее понять структуру
Пустые ячейки без содержания Лучше &nbsp; или пояснительный текст
Вкладывать таблицу в таблицу без причины Обычно признак плохой структуры

14. Что запомнить из урока

  • Таблицы — для данных, не для вёрстки макета.
  • <table> — контейнер, <tr> — строка, <td> — ячейка, <th> — заголовок.
  • Таблица строится по строкам, а столбцы — это ячейки в каждой строке.
  • <caption> — подпись таблицы, идёт сразу после <table>.
  • colspan — растянуть по горизонтали, rowspan — по вертикали.
  • scope="col" / scope="row" — уточнить, к чему относится <th>.
  • Визуальные атрибуты (border, cellpadding, cellspacing) устарели — используй CSS.
  • border-collapse: collapse — убрать двойные рамки.
  • Для доступности: caption + th + scope обязательны для смысловых таблиц.
