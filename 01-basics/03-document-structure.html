Урок 3. Структура HTML-документа

1. Общая картина

Любой правильный HTML-документ имеет 4 обязательных части:

<!DOCTYPE html> ← 1. Объявление типа документа <html lang="ru"> ← 2. Корневой контейнер <head> ← 3. Служебная информация ... </head> <body> ← 4. Видимое содержимое ... </body> </html>

Запомни эту схему как скелет. Всё, что ты будешь писать в HTML, живёт внутри одной из этих частей.

2. <!DOCTYPE html> — объявление типа

Это не тег. Это инструкция браузеру: «этот документ — HTML5». Пишется самой первой строкой, до всего остального. 

<!DOCTYPE html>

Зачем это нужно

В 90-е и 2000-е было несколько версий HTML (HTML 4.01, XHTML 1.0 и др.). Браузеры, встретив старый документ, включают режим совместимости (quirks mode) — там правила отображения немного другие.

Строка <!DOCTYPE html> говорит браузеру: «работай в современном режиме (standards mode)». Без неё страница может выглядеть иначе.

Раньше DOCTYPE выглядел как огромная портянка из URL-адресов и версий. В HTML5 его сократили до одной строки. Запомни: <!DOCTYPE html> — и всё.

Правила написания

  • Пишется один раз, в самом верху файла.
  • Регистр не важен: <!doctype html> тоже работает, но пишут капсом.
  • У него нет закрывающего тега.
  • Перед ним не должно быть ничего — ни пробелов, ни переносов строк, ни комментариев.
Ошибка новичка: ставить комментарии или пустые строки до <!DOCTYPE html>. Некоторые браузеры из-за этого переключаются в quirks mode и ломают вёрстку.

3. <html> — корневой элемент

Всё содержимое страницы заключено в <html>. Это «корень» дерева. Внутри него — ровно два ребёнка: <head> и <body>. 

<html lang="ru">
    <head>...</head>
    <body>...</body>
</html>

Атрибут lang

Указывает язык содержимого. Значение — код языка по стандарту ISO: ru, en, de, fr и т.д.

Зачем это нужно:

  • Поисковики понимают, на каком языке сайт, и показывают его нужной аудитории.
  • Screen reader'ы (программы для незрячих) читают текст правильным голосом и произношением.
  • Браузер знает, как переносить слова, какие кавычки ставить, как проверять орфографию.
<html lang="ru">   <!-- русский -->
<html lang="en">   <!-- английский -->
<html lang="uk">   <!-- украинский -->
Если часть страницы на другом языке (например, цитата на английском), можно повесить lang на конкретный тег: <p lang="en">Hello!</p>. Браузер поймёт, что читать по-английски.

4. <head> — «мозг» документа

Внутри <head> лежит служебная информация. Пользователь её не видит на странице, но она очень важна.

Что там обычно находится:

Тег Назначение Обязательно?
<meta charset> Кодировка документа Да
<meta name="viewport"> Адаптация под мобильные Да (для современного сайта)
<title> Заголовок вкладки Да
<meta name="description"> Описание для поисковиков Желательно
<link> Подключение CSS, favicon По необходимости
<style> CSS прямо в документе Не рекомендуется
<script> JavaScript По необходимости

<meta charset="UTF-8"> — кодировка

Самая важная строка в <head>. Она говорит браузеру, как читать байты, из которых состоит файл.

UTF-8 — современный стандарт, поддерживает все языки мира (кириллицу, иероглифы, эмодзи). Всегда используй UTF-8.

Такие «крякозябры» называются mojibake. Значит, кодировка не совпала.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Строка для мобильных устройств. Без неё смартфон откроет страницу «как на компьютере» и уменьшит её — придётся вручную приближать.

Разберём по частям:

  • width=device-width — ширина страницы = ширина экрана телефона.
  • initial-scale=1.0 — начальный масштаб 100% (без зума).
Проверить: открой этот урок в браузере, нажми F12, включи режим устройства (Ctrl+Shift+M) и выбери iPhone. Если бы viewport не был указан, текст был бы микроскопическим.

<title> — заголовок вкладки

Текст, который видно на вкладке браузера, в закладках и в результатах поиска Google. 

<title>Урок 3. Структура HTML-документа</title>

Правила хорошего заголовка:

  • Уникальный для каждой страницы.
  • Короткий (до 60 символов), иначе обрежется в поисковике.
  • Описывает содержимое: «Купить кота — Магазин Мурлыка», а не просто «Главная».

<meta name="description">

Краткое описание страницы. Используется поисковиками для сниппета (короткого текста под ссылкой в результатах поиска). 

<meta name="description" content="Урок 3 про структуру HTML: DOCTYPE, html, head, body">

<link> — подключение ресурсов

Чаще всего используется для подключения CSS-файла (стилей): 

<link rel="stylesheet" href="style.css">

И для favicon (иконка вкладки):

<link rel="icon" href="favicon.ico">

5. <body> — «тело» документа

Здесь лежит всё, что видит пользователь: текст, картинки, кнопки, формы, видео. 

<body>
    <h1>Добро пожаловать!</h1>
    <p>Это моя первая страница.</p>
    <img src="cat.jpg" alt="Кот">
</body>

По правилам HTML внутри <body> может быть сколько угодно элементов — ограничений нет.

6. Аналогия для запоминания

Представь книгу:
  • Обложка / ISBN → <!DOCTYPE html> (метаданные о книге)
  • Сама книга → <html> (весь том)
  • Титульный лист, оглавление, аннотация → <head> (служебное)
  • Главы, текст, картинки → <body> (то, что читают)
Или так: <head> — это мозг (не видно, но управляет), <body> — это тело (видно всем).

7. Что НЕЛЬЗЯ делать

Ошибка Почему плохо
Писать текст вне <body> Пользователь его не увидит, браузер может сам «перекинуть» его в body, но валидность нарушена
Класть <title> в <body> Не сработает — браузер ищет его только в <head>
Несколько <head> или <body> По стандарту — ровно по одному
Забыть <!DOCTYPE html> Браузер переключится в quirks mode, возможны баги
Писать контент прямо в <html>, минуя body Браузер сам обернёт в body, но лучше так не делать
Забыть <meta charset> Кириллица превратится в «крякозябры»

8. Проверь сам: что произойдёт без DOCTYPE?

Создай файл test-no-doctype.html с таким содержимым: 

<html>
<head>
    <meta charset="UTF-8">
    <title>Без DOCTYPE</title>
</head>
<body>
    <p>Проверяем режим документа</p>
</body>
</html>

Открой в браузере, нажми F12 и введи в консоль:

document.compatMode

Увидишь "BackCompat" — это quirks mode.
А если добавить <!DOCTYPE html> — станет "CSS1Compat" (standards mode).

Попробуй прямо сейчас — это лучший способ убедиться, что DOCTYPE реально влияет на браузер.

9. Шаблон, который стоит выучить наизусть

Открой VS Code, набери ! и нажми Tab — Emmet развернёт готовый шаблон. Но ты должен понимать, что там написано:

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Название страницы</title>
</head>
<body>

</body>
</html>

Это твой стартовый каркас для любой страницы. Через пару недель ты будешь писать его на автомате.

10. Практическое задание

Задание 1. «Собери каркас с нуля»

Создай 03-practice.html. Набери руками (без Emmet!) такой каркас:

  • <!DOCTYPE html>
  • <html lang="ru">
  • В <head>: charset UTF-8, viewport, title «Мой третий урок»
  • В <body>: заголовок h1 «Проверка структуры» и параграф

Задание 2. «Поиграй с meta»

  • Добавь <meta name="description" content="Это моя тренировочная страница">
  • Добавь <meta name="author" content="Твоё имя">
  • Открой исходник в браузере (Ctrl+U) — убедись, что мета-теги видны, а на странице их нет.

Задание 3. «Сломай и почини»

  • Убери <meta charset="UTF-8"> → посмотри, появятся ли крякозябры (может понадобиться переоткрыть файл).
  • Помести текст прямо в <html>, вне <body> → проверь через F12, куда браузер его «перекинул».
  • Помести <title> в <body> → убедись, что вкладка так и называется «по умолчанию».

Задание 4. «Проверка DOCTYPE»

  • Создай файл без <!DOCTYPE html>.
  • Открой консоль, введи document.compatMode.
  • Сравни с файлом, где DOCTYPE есть.

11. Что запомнить из урока

  • <!DOCTYPE html> — первая строка, включает standards mode. Без него — quirks mode.
  • <html lang="ru"> — корень всего. Атрибут lang помогает поисковикам и screen reader'ам.
  • <head> — служебная информация: charset, viewport, title, description, link на CSS.
  • <body> — видимое содержимое. Только здесь живёт то, что видит пользователь.
  • Порядок: DOCTYPE → html → (head, body). Оба внутри html — ровно по одному.
  • UTF-8 обязателен, иначе кириллица ломается.
  • Viewport обязателен для мобильных устройств.
  • Шаблон = Emmet + ! + Tab, но понимание важнее скорости.
