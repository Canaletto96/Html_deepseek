Урок 4. Метатеги

1. Что такое метатеги и зачем они нужны

Метатеги — это теги в <head>, которые описывают сам документ. Пользователь их не видит на странице, но их читают:

  • Браузер — чтобы правильно отобразить текст и подогнать под экран.
  • Поисковики (Google, Яндекс) — чтобы понять, о чём страница и показать её в выдаче.
  • Социальные сети — чтобы построить красивую карточку при шаринге ссылки.
  • Программы для незрячих — чтобы правильно произносить текст.
Аналогия. Если HTML-документ — это книга, то метатеги — это её аннотация, ISBN, информация об авторе и издательстве на титульном листе. Читатель книгу читает, а метаданные нужны библиотеке и магазину.

2. Тег <meta> — основной инструмент

Почти вся служебная информация задаётся через <meta>. Это одиночный тег (нет закрывающего) с обязательной парой атрибутов. Работает по одной из четырёх схем:

Схема Пример Назначение
charset <meta charset="UTF-8"> Кодировка
name + content <meta name="description" content="..."> Именованные метаданные
http-equiv + content <meta http-equiv="refresh" content="30"> Эмуляция HTTP-заголовков
property + content <meta property="og:title" content="..."> Open Graph (соцсети)

Разберём каждую схему по порядку.

3. Charset — кодировка

Говорит браузеру, как читать байты файла. Самая важная строка в <head>.

<meta charset="UTF-8">

Значения:

  • UTF-8 — современный стандарт, поддерживает все языки мира. Всегда используй его.
  • windows-1251 — старая кириллическая кодировка.
  • ISO-8859-1 — старая западноевропейская.

4. Viewport — адаптация под мобильные

Без этого тега смартфон откроет страницу так, будто у него экран шириной как у монитора (обычно 980px), а потом просто уменьшит всё. Текст станет микроскопическим, придётся зумить пальцами. 

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Расшифровка значений внутри content:

Значение Что делает
width=device-width Ширина вьюпорта = ширина экрана устройства
initial-scale=1.0 Начальный масштаб 100%, без зума
maximum-scale=5.0 Максимальный зум (редко нужно)
user-scalable=no Запрет зума (плохо для доступности)
Минимальный набор — width=device-width, initial-scale=1.0. Этого достаточно в 99% случаев. Не запрещай зум через user-scalable=no — это ломает доступность для людей с плохим зрением.

5. Description — описание для поисковиков

Краткое описание страницы. Google и Яндекс могут показать его в сниппете — коротком тексте под ссылкой в результатах поиска. 

<meta name="description" content="Уроки HTML для начинающих: структура, теги, атрибуты, метаданные.">

Правила хорошего description:

  • Длина — 120–160 символов. Длиннее — обрежется.
  • Уникальный для каждой страницы.
  • Описывает пользу страницы, а не просто «это главная».
  • Без «воды» вроде «добро пожаловать на наш сайт».
Важно: Google не гарантирует, что покажет твой description. Часто он сам составляет сниппет из текста на странице. Но если description хороший — шанс, что покажут именно его, выше.

6. Title — заголовок вкладки

Не <meta>, а отдельный тег, но по смыслу — важнейший «метатег». Показывается на вкладке, в закладках и в результатах поиска (как жирная синяя ссылка). 

<title>Урок 4. Метатеги — всё о &lt;meta&gt;</title>

Правила:

  • Длина — до 60 символов.
  • Уникальный для каждой страницы.
  • Начинай с важного: «Урок 4. Метатеги», а не «Мой блог — Урок 4».
  • Бренд — в конец: «Как варить кофе — Блог Ивана».
Обрати внимание на &lt;meta&gt; в примере выше — это HTML-сущность. Угловые скобки внутри <title> нужно экранировать, иначе браузер подумает, что это настоящий тег.

7. robots — инструкции для поисковиков

Говорит поисковым роботам, что делать со страницей.

<meta name="robots" content="index, follow">

Значения (через запятую):

Значение Что значит
index Разрешить индексировать страницу (по умолчанию)
noindex Не индексировать страницу
follow Переходить по ссылкам на странице (по умолчанию)
nofollow Не переходить по ссылкам
noarchive Не показывать копию в кэше
nosnippet Не показывать сниппет в результатах

Пример: страница, которую не нужно индексировать —

<meta name="robots" content="noindex, nofollow">

8. Open Graph — красивые превью в соцсетях

Когда ты кидаешь ссылку в Telegram, WhatsApp или Facebook, мессенджер строит «карточку» с картинкой, заголовком и описанием. Данные для неё берутся из Open Graph (OG).

OG-теги используют атрибут property (не name):

<meta property="og:title" content="Урок 4. Метатеги">
<meta property="og:description" content="Учимся настраивать документ для поиска и соцсетей.">
<meta property="og:image" content="https://example.com/preview.jpg">
<meta property="og:url" content="https://example.com/lesson-4">
<meta property="og:type" content="article">

Основные OG-теги:

Свойство Что задаёт
og:title Заголовок карточки
og:description Описание карточки
og:image Картинка-превью (рекомендуется 1200×630 px)
og:url Канонический URL страницы
og:type website, article, video.movie и др.
og:site_name Название сайта
og:locale Язык: ru_RU, en_US
Отдельно для Twitter есть свои теги с префиксом twitter:: twitter:card, twitter:title, twitter:image. Часто Twitter автоматически подхватывает OG-теги, но для точного контроля добавляют и их.

9. http-equiv — эмуляция HTTP-заголовков

Позволяет задать поведение, которое обычно приходит от сервера, прямо в HTML. Сегодня почти не используется, кроме пары случаев. 

<!-- Автообновление страницы через 30 секунд -->
<meta http-equiv="refresh" content="30">

<!-- Редирект через 5 секунд -->
<meta http-equiv="refresh" content="5; url=https://example.com">
Осторожно с refresh! Автоматический редирект через http-equiv="refresh" — плохая практика: ломает кнопку «Назад», путает пользователей и поисковики. Для редиректов используй серверные заголовки (301/302), а не HTML.

10. Другие полезные метатеги

Тег Назначение
<meta name="author" content="..."> Автор документа
<meta name="keywords" content="html, css"> Ключевые слова (поисковики игнорируют)
<meta name="theme-color" content="#b5651d"> Цвет адресной строки на мобильных
<meta name="google-site-verification" content="..."> Подтверждение прав в Google Search Console
<meta name="format-detection" content="telephone=no"> Отключить автоссылки на телефоны (iOS)

11. Полный шаблон современного <head>

Вот рекомендуемый набор метатегов для типовой страницы:

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Название страницы — Название сайта</title>
    <meta name="description" content="Краткое описание страницы, 120-160 символов">
    <meta name="author" content="Имя автора">

    <!-- Open Graph для соцсетей -->
    <meta property="og:title" content="Название страницы">
    <meta property="og:description" content="Описание">
    <meta property="og:image" content="https://example.com/preview.jpg">
    <meta property="og:url" content="https://example.com/page">
    <meta property="og:type" content="website">

    <!-- Подключение стилей и иконки -->
    <link rel="stylesheet" href="style.css">
    <link rel="icon" href="favicon.ico">
</head>

Это — золотой минимум. Всегда начинай с этого шаблона.

12. Как проверить свои метатеги

  • Исходный код в браузере — Ctrl+U, найди <head> и проверь.
  • Панель разработчика — F12 → Elements → разверни <head>.
  • Проверка OG — сервисы вроде opengraph.xyz или developers.facebook.com/tools/debug покажут, как выглядит превью.
  • Валидатор HTML — validator.w3.org проверит, нет ли ошибок в разметке.

13. Практическое задание

Задание 1. «Полный head с нуля»

Создай файл 04-practice.html. Собери <head> по образцу из раздела 11, но со своими данными:

  • charset и viewport — как в шаблоне.
  • title — «Моя страница о котах».
  • description — 120–150 символов о том, что на странице.
  • author — твоё имя.
  • og:title, og:description, og:type="website".
  • В body — <h1> и пару абзацев.

Задание 2. «Проверка в браузере»

  • Открой 04-practice.html в браузере.
  • Нажми Ctrl+U — найди свои метатеги в исходнике.
  • Нажми F12 → вкладка Elements — посмотри, как браузер видит <head>.
  • Посмотри на вкладку браузера — там должен быть твой title.

Задание 3. «Сломай и почини»

  • Убери <meta charset="UTF-8">, сохрани файл в кодировке windows-1251 (в VS Code — «Reopen with Encoding» → «Save with Encoding»), открой в браузере. Что случилось?
  • Поменяй title на что-то короткое и длинное — посмотри, как это обрезается на вкладке.
  • Добавь <meta http-equiv="refresh" content="5"> — страница будет обновляться каждые 5 секунд. Убедись, потом удали.

Задание 4. «Open Graph»

  • Открой сайт opengraph.xyz.
  • Введи URL любой известной страницы (например, https://developer.mozilla.org/ru/).
  • Посмотри, какие OG-теги использует MDN. Сравни со своим файлом.

14. Что запомнить из урока

  • <meta charset="UTF-8"> — обязательно, первым в <head>.
  • <meta name="viewport" content="width=device-width, initial-scale=1.0"> — обязательно для мобильных.
  • <title> — уникальный, до 60 символов, на каждой странице.
  • <meta name="description"> — 120–160 символов, уникальный.
  • <meta name="robots"> — управляет индексацией (index/noindex, follow/nofollow).
  • Open Graph (og:*) — для красивых превью в соцсетях.
  • http-equiv="refresh" — плохая практика для редиректов, используй серверные заголовки.
  • У схем <meta> четыре вида: charset, name, http-equiv, property.
