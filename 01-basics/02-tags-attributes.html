Урок 2. Теги, атрибуты, вложенность, комментарии

1. Из чего состоит элемент

Мы уже знаем, что тег — это команда в угловых скобках. Но у любого элемента HTML есть анатомия. Разберём её на примере ссылки: 

<a href="https://example.com" target="_blank">Открыть сайт</a>

Этот элемент состоит из частей:

Часть Что это В примере
Открывающий тег Имя тега в скобках <a ...>
Атрибут Свойство элемента (имя="значение") href="https://example.com"
Атрибут Ещё одно свойство target="_blank"
Содержимое Текст или другие теги Открыть сайт
Закрывающий тег Со слэшем </a>
Атрибут — это всегда пара имя="значение". Имя без кавычек писать нельзя. Кавычки могут быть двойные " или одинарные ', но двойные — стандарт.

2. Где живут атрибуты

Атрибуты пишутся только в открывающем теге. В закрывающем их не бывает. 

<!-- ПРАВИЛЬНО -->
<p class="intro" id="first">Текст</p>

<!-- НЕПРАВИЛЬНО — атрибуты в закрывающем теге бессмысленны -->
<p>Текст</p class="intro">

Порядок атрибутов не важен. Между ними — пробелы. Значения можно писать в любом порядке, главное чтобы они не повторялись у одного элемента.

3. Основные атрибуты, которые ты будешь использовать часто

id — уникальный идентификатор

Как «номер паспорта» элемента. Должен быть один на странице и только один. Служит для якорей, стилей и JavaScript. 

<h2 id="section-1">Раздел 1</h2>

class — имя класса

Как «фамилия» — может повторяться у многих элементов. Используется для стилизации. У одного элемента может быть несколько классов через пробел. 

<p class="text important">Жирный текст</p>

style — инлайн-стиль

Позволяет задать CSS прямо в теге. Мы почти не будем его использовать (стили принято выносить в отдельный файл), но знать нужно. 

<p style="color: red; font-size: 20px;">Красный текст</p>

title — подсказка

Всплывающий текст при наведении мыши. Работает почти на любом элементе. 

<abbr title="HyperText Markup Language">HTML</abbr>

hidden — скрыть элемент

Это булев атрибут: либо он есть, либо его нет. Значение писать не нужно. 

<p hidden>Этот текст не видно</p>
Булевы атрибуты. Есть атрибуты, которые не требуют значения — само их присутствие уже «включает» поведение. Например: hidden, disabled, required, checked. Их можно писать как disabled или disabled="disabled" — оба варианта валидны.

4. Вложенность — теги внутри тегов

Теги можно вкладывать друг в друга. Это главный приём HTML. Правило простое: закрывающий тег — зеркален открывающему в обратном порядке. 

<p>
    Это <strong>жирный</strong> и <em>курсивный</em> текст.
</p>

Здесь <strong> и <em> находятся внутри <p> — это их «родитель».

Правильное закрытие

Представь матрёшку или коробки: закрывать нужно в обратном порядке.

<!-- ПРАВИЛЬНО: сначала открыли A, потом B → закрываем B, потом A -->
<p>Текст <strong>важный</strong> конец</p>

<!-- НЕПРАВИЛЬНО: теги "пересеклись" -->
<p>Текст <strong>важный</p></strong>
Пересечение тегов — грубая ошибка. Браузер, скорее всего, «починит» её сам, но результат может быть неожиданным. Всегда следи за закрытием в правильном порядке.

Три уровня вложенности

<div>
    <p>
        Абзац с <strong>жирным <em>и курсивным</em></strong> словом.
    </p>
</div>

Попробуй мысленно раскрыть: div > p > strong > em. Это называется дерево.

5. Отступы — «воздух» в коде

Браузер игнорирует отступы, но ты их видишь. Соглашение: каждый уровень вложенности сдвигается вправо на 2 или 4 пробела. 

<body>
    <div>
        <p>
            Текст с <strong>акцентом</strong>.
        </p>
    </div>
</body>

В VS Code: выдели код и нажми Shift + Alt + F — редактор сам расставит отступы. Настрой это сразу, чтобы потом не мучиться.

6. Комментарии

Комментарии — заметки для людей. Браузер их не отображает и не выполняет. 

<!-- Это комментарий -->

Где они полезны

  • Пометки блоков — чтобы найти нужное место в длинном файле.
  • Пояснения — «зачем эта строка».
  • Временное отключение кода — чтобы проверить что-то без удаления.
<!-- Начало шапки сайта -->
<header>...</header>
<!-- Конец шапки -->

<!-- <p>Этот абзац временно скрыт</p> -->

Правила

  • Начало: <!-- (два дефиса!)
  • Конец: --> (два дефиса!)
  • Внутри комментария нельзя писать -- подряд, это ломает разметку.
  • Многострочные комментарии разрешены.
Частая ошибка новичков: написать <!- текст -> (один дефис). Так комментарий не закроется, и браузер съест полстраницы.

8. Частые ошибки новичков

Ошибка Как правильно
<p>Текст<p> <p>Текст</p> — забыт слэш
<p>Текст</p/> Слэш идёт до имени тега: </p>
<p class=intro> <p class="intro"> — кавычки обязательны
<p>текст</strong></p> Закрывающий тег должен совпадать с открывающим
<p><strong>текст</p></strong> Пересечение тегов — так нельзя
<!- комментарий -> <!-- комментарий --> — по два дефиса
Два одинаковых id на странице id должен быть уникален, используй class

9. Практическое задание

Задание 1. «Карточка кота»

Создай файл 02-practice.html. Напиши каркас страницы (<!DOCTYPE html>, <html>, <head>, <body>).

Внутри <body> построй такой блок:

  • Заголовок <h1> с id="cat-title"
  • Параграф про кота с class="description important" (два класса!)
  • Внутри параграфа — одно слово в <strong>, другое в <em>
  • Параграф с аббревиатурой «HTML» через <abbr title="...">
  • Один параграф со style="color: green;"
  • Один параграф с атрибутом hidden

Задание 2. «Комментарии»

  • Сверху файла добавь комментарий с датой и своей целью: «Учусь HTML».
  • Оберни один из абзацев в комментарий (закомментируй его) — убедись, что он исчез со страницы.

Задание 3. «Сломай и почини»

  • Специально перепутай порядок закрытия тегов <strong> и <em> — посмотри, что сделает браузер.
  • Забудь закрыть <div> — что произойдёт со всем, что ниже?
  • Напиши два одинаковых id — браузер поругается в консоли (F12 → Console).

10. Что запомнить из урока

  • Элемент = открывающий тег + содержимое + закрывающий тег (иногда только открывающий).
  • Атрибут пишется в открывающем теге, всегда в кавычках: имя="значение".
  • id — уникален, class — повторяем, style — для быстрых правок.
  • Вложенность — как матрёшки: закрываем в обратном порядке.
  • Отступы нужны тебе, а не браузеру. Shift + Alt + F в VS Code.
  • Комментарии: <!-- текст -->, по два дефиса с каждой стороны.
